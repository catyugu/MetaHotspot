# 可审计研究记录规范 v2（Robin HTC）

每份实验记录必须明确：研究问题/可证伪假设；真实连接端口 `g` 与内部 Robin 面 `b` 的区分；`H_j`、HTC 盒、外界温度驱动 `h_j b_j T_infty,j`；训练/持出 HTC 点；实际零/非零频率样本；单一固定误差标度；独立 DtN、功耗/测温与环境温度传递；实际 ROM 秩；全阶 LU/RHS、低阶求解/认证开销；状态保结构；脚本命令/库版本/起始 Git SHA。失败与成本反例必须保留。

证据等级：**P** 完整假设下精确算术证明，**B** 普通浮点评估的解析充分界，**N** 有限点数值，**O** 性能观察，**L** 文献（标注仅摘要/正文/代码）。结论另标 POSITIVE / NEGATIVE / MIXED / INCONCLUSIVE。只有外向舍入及连续域有效覆盖才能标 verified certificate；数值 Hamiltonian H∞、角点通过、静态保证、逐频扫描均不能冒充它。

文献记录包含准确题目、作者、年、DOI、阅读深度、参数/输出/保证域/方法成本及先例重叠。不得自称发明参数灵敏度 Krylov、Bernstein BRL 或普通 H∞ 计算。不提交大型 CSV/JSON/Numpy 数组、矩阵、日志；只保留小汇总、复现命令和源码。
