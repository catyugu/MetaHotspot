# End-to-end AMG reuse experiment

## Question and hypothesis

This experiment asks whether rebuilding AMG once per shared frequency, then reusing that hierarchy across boundary coefficients and heat-source ports, reduces the complete cost of extracting a parametric thermal ROM. The hypothesis is that full extraction wall time falls by at least ten percent while final model accuracy and response-space size remain comparable. A slower cached method, an enlarged response space, or material accuracy degradation counts as a negative result. Setup-only acceleration will not be described as end-to-end acceleration.

The reference implementation is the current dev revision deb981297d1353d9005e0a042657e1d8eef0e595. Its production extractor computes spectral endpoints separately for each port, constructs a random adaptive response space per port, compresses all physical response snapshots by SVD, and preserves the constant-temperature mode. The user has established shared global spectral endpoints as the intended premise for this experiment. Both comparison arms therefore use the same globally estimated endpoints and identical elliptic frequency sequence. Replacing the port-specific frequency plans is a common controlled change; its computational benefit cannot be attributed to AMG reuse.

## Benchmark binding

The sole primary benchmark is the original Case-1 layered heat-sink model from the repository, using its default 0.5 mm maximum cell size. It contains aluminium, two thin TIM layers, copper, and four unequal silicon heat sources. Current native assembly gives 146704 degrees of freedom. The three exposed boundary groups have independent physical HTC ranges from 1 to 10000 W/(m2 K). Physical coefficients are converted into the effective affine coefficient box by the model's existing conversion. This combination tests the intended application and broad boundary uncertainty without replacing the existing benchmark with an easier synthetic matrix.

One benchmark is sufficient for a first decision about this repository's extraction workflow, but not for claiming general mesh-independent or material-independent acceleration. The native wheel and Python source must have matching revisions. Geometry generation is run before the extraction timer and reported separately because both methods consume identical assembled operators. All three methods traverse matching frequencies in the outer loop and source ports in the inner loop. Each source retains its own local response basis and affine Galerkin projection across frequencies. This is necessary to finish all consumers of a frequency before replacing the AMG object. The shared random stream is consequently consumed in frequency-major order in all arms, so this rerun is the controlled comparison. The extraction timer includes global spectral estimation, response generation, residual probing, local orthogonalization, incremental reduced operators, snapshot SVD, constant-mode insertion, and final BCI projection.

## Methods and controlled differences

Fresh builds a Ruge-Stuben hierarchy at the actual sampled matrix for every rejected reduced response requiring a full solve. Port-cache builds one hierarchy for the lower-HTC reference matrix at each frequency and each source port. Shift-cache uses the same lower-HTC reference but shares each frequency hierarchy across all ports. The experimental extractor is a frequency-major adaptation of the released extractor; the production implementation remains intact. Each hierarchy uses direct interpolation, a Cholesky coarse solve, and a V-cycle, matching the baseline helper. No diagonal scaling is added.

The lower-bound reference at fixed frequency is Kmin+sC. Each full response still solves its actual K+sC+sum(pj Hj) matrix. The preconditioner alone is frozen. PCG warm starts, maximum iterations, stopping tolerance, and all random draws are unchanged. Only one hierarchy is cached at a time. When a completed frequency is replaced, the old hierarchy is released before the new setup begins; port-cache similarly replaces the cache when either its source port or frequency changes. All hierarchies are discarded at the end of each complete extraction. This prevents a warm cache in one run from subsidizing another. The initial port-major all-frequency-cache run is archived as superseded evidence and is excluded from headline timing and accuracy summaries. The port-cache ablation separates gains from boundary-sample reuse from the smaller additional gain available through cross-port sharing.

## Metrics and timing boundaries

The headline metric is total extraction seconds, lower being better. Paired speedup divides fresh wall time by the cached run for the same seed. Components are spectral estimation, AMG setup, PCG solve, final snapshot SVD, final BCI projection, and the remaining probing and basis work. Components partition the timer rather than summing nested timers. Each full solve records frequency, source port, sampled effective HTC, CG iterations, true relative residual, setup seconds, and CG seconds. Counts of setups and full responses help explain whether a timing gain comes from cheaper preparation or a changed adaptive path.

Accuracy metrics include final order, snapshot count, maximum true linear residual, and held-out steady and transient junction and full-field errors. Errors in kelvin are accompanied by errors normalized by the maximum full-model temperature rise, since nearly adiabatic corners produce much larger absolute temperatures than strongly cooled points. Identical basis dimensions are desirable but cannot be assumed: a different preconditioner can perturb an inexact response enough to alter a subsequent randomized acceptance decision.

## Execution protocol

Three paired seeds, 20260805 through 20260807, are used for complete extractions. Methods alternate order between repeats to reduce monotonic runtime drift. BLAS and OpenMP threads are fixed to one for reproducible CPU timing; the experiment does not claim multithreaded production throughput. Hardware, Python and numerical-library versions, repository revision, commands, and source hashes are written with raw results. One initial global-spectrum calculation is a preflight only and is not substituted for the measured estimation inside any extraction. Each timed method estimates the shared spectrum once itself.

No hyperparameter search is performed. Tolerance remains 1e-3, response PCG tolerance is 1e-4, probe rounds are ten, and maximum snapshot count is 1024, matching the reproduction script. A short run may diagnose a failure but cannot replace a completed extraction in the headline table. Every completed run is persisted immediately so a later failure does not erase measured evidence.

## Validation and attribution

Held-out evaluation uses the eight physical HTC corners, the nominal coefficient vector, and four independent log-uniform coefficient vectors. Three points also receive a transient power-step comparison using the same BDF1 discretization. Reference linear solves use tighter tolerances than extraction. Accuracy evaluation is excluded from extraction timing and is reported as an independent cost. Direct comparisons between methods use physical output fields rather than basis vectors, whose coordinates can rotate without changing the ROM.

The port-cache ablation is expected to capture most saved setups if multiple boundary samples are needed at each frequency. Shift-cache can then save the remaining duplicate setups across four ports. That extra gain may be small, especially when many high-frequency responses require no new full solve. The experiment reports observed setup frequencies and adaptive response counts rather than assuming all four ports use every matching point.

## Budget and limitations

The initial budget is three complete runs per method on this CPU, with sequential execution and a target duration under one hour. Validation and plotting have a separate budget of about fifteen minutes. There is no new production test suite and no change to solver tolerances to force a favorable result. Timing variability is summarized by mean and sample standard deviation; three seeds are not sufficient for a strong population-level statistical claim. A single benchmark cannot establish reliability under severe conductivity contrasts, different HTC layouts, nonconformal meshes, or a different AMG implementation. The final decision will therefore concern this extraction workload, with the measured error and adaptive-space changes stated explicitly.
