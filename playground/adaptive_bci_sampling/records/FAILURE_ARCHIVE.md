# 失败路线档案

当前验收与默认实验入口见 [README](../README.md)。下述早期条目中的“当前目标”按历史语境理解，尤其冲激积分范数不替代当前阶跃验收；其 `THEORY.md` 与旧实现已移至 [历史归档](../archive/legacy20261007/README.md)。后续判决见本文件末尾。

2026-10-08/09 旧方案已整体移至 [研究归档](../archive/research20261008_09/README.md)。以下历史条目的裸文件名按对应归档解释；当前唯一主入口以 README 为准。

本目录**唯一**的失败路线档案。它只记录**为什么某条路线被淘汰**。

判定只取五类：

```text
被反例证伪      命题、假设、单调性、等价关系本身不成立，或前提在实测数据上直接失效
界太松          不等式成立，但 effectivity 差到不能承担证书任务
成本不可行      理论与精度都成立，但复杂度、求解数、分解数、墙钟或内存不可接受
测量更正        结论来自实现缺陷或测量缺陷（bug、计数、求解器、配置），原数字撤回
实验不可比      测量本身可能都对，但比较对象不是同一个对象（基、网格、容差、参数盒、求解器设置等出处不一致）
```

判定记录的是"为什么被淘汰"，不是成熟度或适用条件。因此"方向对但证明还不完备"与"只在粗 cell 上
失败、细化后通过"**都不作为判定类**：前者属于成熟度，只能写进末尾的"未闭合路线"一节；后者仍是
`界太松`，但作用域必须带上条件（例如"粗 HTC cell"）。同理，**每条的路线必须写成足够精确的命题，
而不是只写方法名**：不写"degree-1 Bernstein 失败"，要写"degree-1 Bernstein + 全空间算子范数曲率，
在粗 HTC cell 上不作细化直接使用，失败"。`实验不可比` 与 `测量更正` 的界线是：影子变量、计数错误、
把采样 sup 当成严格 sup 属于 `测量更正`；基容差或阶数不同却把两个 sup 直接比较，属于
`实验不可比`——此时两次测量各自都正确。

每条还带一个**作用域标签**，说明失败证据是在哪个度量下取得的：

```text
STATE           全场 / A-能量 / 状态传递算子范数
PORT-SYSTEM     H2 / Hankel / 冲激响应端口范数（含交付量 epsilon_imp）
PORT-FIXED-S    单个实频移上的共址端口缺陷
PORT-STEP       采样 step-response 度量
COST            N_RHS / setup / 墙钟 / 内存
CORRECTION      实测 bug 或定义错位
```

**作用域标签的结论上限（本文件最重要的纪律）.** 标着 `PORT-FIXED-S` 或 `PORT-STEP` 的条目只证明
"该方案在这个固定实移 / 采样步进诊断下失败"，**不**证明它不可能满足 port-Hankel / 冲激响应系统范数，
也**不**否定同一套参数点或同一套基底构造思想在系统范数目标下重新采用；依据是历史端口桥的一阶反例
（fixed-`s` 的同址平方关系不推出动态系统范数误差也平方）。反过来，标着 `PORT-SYSTEM` 的条目是
直接对动态系统范数成立的判决。

**目标边界.** 研究目标是全场传递算子 `X(p,s) = A(p,s)^-1 G`，因此仅凭全场 / A-能量 / 状态范数判据的
失败条目**同样是**当前目标下的负结果；它在定频上的实现就是 `THEORY.md` 命题 1 的共址缺陷。
未经算法前提核验的 n-width 最优性宣称与未定义范数的 vendor 常数仍不使用。正文撤回（陈述不准、
定义写错、范围写大，方法本身未被否定）留在 `README.md` / `THEORY.md` 正文，不进本文件；
开放候选路线也不进本文件——**"某条路线关闭"绝不等于"它所属的上位问题关闭"**。

**关于复现.** 许多条目所依据的实验，其脚本已在收束中退役，本文件不再引用它们；仍然维护、
可直接运行的脚本见 `README.md` 的文件清单。记录里没有给出命令的，本条照实写"记录未给出"。

## 历史端口动态桥：一阶反例（PORT-SYSTEM，被反例证伪）

**主张**：只依赖 matching resolvent 缺陷 `delta_star` 的**二次**动态桥，可以把连续盒证书接到端口
FANSTIC 式动态保证上。

**为什么淘汰**：在人造质量白化问题上沿 `delta_star -> 0` 测 H2 / Hankel 距离的局部阶，**传输指数是 1
而不是 2**（二阶比随扰动角趋于零增长数个量级），跨四个数量级条件数结论一致。机制是匹配条件本身：
matching 点上取值误差确为 `O(delta^2)`，但 Galerkin 只给 `x_V^T (B + sigma I) e = 0`，不是
`x_V^T e = 0`，所以导数失配一般只有 `O(delta)`。

**未否证的**：使用 matching 缺陷之外结构（Hermite / 导数 / 跨 shift 信息）的二次陈述；以及对
`delta_star` **线性**的候选（骨架常数 `rho_Sigma ~ 3e-2`、`K_vec` 上确界约 `1.4e2`，在 13 频移计划、
`t >= 0`、约 400 行上无违反，中位紧度因子 2 到 5；两者是数值解析的上确界，不是计算机认证的包络）。
此判决不等于 `THEORY.md` P0 的全场 impulse 判决。

## 认证与误差界路线

**A1 全局 matrix-fractional Bernstein 残差证书 + 均匀 Neumann 界**（PORT-SYSTEM + PORT-FIXED-S + COST；界太松，局部分支另有成本不可行）
证书的绝对界离 1e-3 目标两到三个数量级；压到 1e-3 相对误差需要约 2600 到 3000 阶。±1% 盒在 5 mm 上
差约一个数量级，单个 ±50% 盒不过。证书耗时约是同一基同一次提取的九十倍。

**A2 全盒 Taylor jet 参数盒证书（旧成本结构）**（PORT-STEP + COST；成本不可行）
一阶只覆盖 ±0.25%、二阶 ±2%、三到四阶 ±5% 到 ±10%；最难的参数中心要到 7 阶才证 ±10%，而它四阶的界
比目标大三个数量级；每盒数秒到十几秒且没有全域盒数与误差上界。**只否掉当时的全盒实现**：现行的
cell-local polynomial trial + Riesz--Bernstein 单元证书不受影响。

**A3 单元 Neumann / Chebyshev 逆多项式 + 张量 Bernstein 盒（旧加权与旧实现）**（COST；成本不可行）
两族都做了上千次局部中心求值、各留数百个失败单元，把阶数升到 12 阶仍闭合 0 个；另试上千次
de Casteljau 细分同样闭合 0 个。否掉的是代价结构，不是"单元多项式 trial + Bernstein 包络"。

**A4 Reduced Neumann--Bernstein 残差盒原型**（PORT-FIXED-S + COST；成本不可行）
三阶时十几个频移全部闭合，但界本身的耗时比 stock 单次提取高一个多数量级；一阶只闭合一半、
二阶大部分闭合；提高秩几乎不减少单元数。

**A5 单一全局谱标量的廉价盒残差界**（PORT-FIXED-S；界太松）
恒等式与包围本身成立（Loewner 与逐元违反均为 0），但 effectivity 中位数十几到上百、最大到 1e5；
在设定误差的点上界给出 O(1) 而真值在 1e-5 到 1e-4 量级。只能作排序优先级分数，绝不能作停止规则。

**A6 BDF1 输出残差证书（K_min^-1 全局 Gram + 见证空间）**（PORT-STEP；界太松）
不等式成立，但比实测松约四十倍；局部化为精确 `K(p)^-1` 之后仍松一到两个数量级，即换参数锚点
救不了这个停止测试。同条确认：vendor 的"全空间-时间温度能量"范数在可取得材料中没有定义，
故不作 `delta_req` 第二项。

**A7 post-SVD 压缩效应诊断：raw majorant 不能认证交付 ROM**（PORT-FIXED-S + PORT-STEP；被反例证伪，含测量更正）
两个网格上都出现 raw 最坏步误差比 final 低两到三个数量级，压缩把步误差放大约三十到一百五十倍
（稳态约十八倍）。否掉的是"raw 空间的 convex-corner majorant 可认证 post-SVD 交付 ROM"这一
**数学迁移**；压缩作为证明义务已由"认证最终交付 V 本身"替代。

**A8 频率计划谱区间缺陷（修复已撤回）**（PORT-FIXED-S + CORRECTION；被反例证伪）
低 HTC 角的误差是容差的数倍，而盒合法计划在同一点好两个多数量级。旧的两倍以上读法属于测量更正
（cache 只按 shift 值作键），纠正后量级降到容差的 1 到 6 倍。FANSTIC 精确矩参考本身未被证伪；
**仅为历史测量，不代表当前生产路径**。

**A10 频率轴（Hankel）整盒证书**（PORT-SYSTEM；界太松 + 成本不可行）
把锚定 Riesz 论证搬到含频率的算子上：传递误差上确界比整模型 Hankel 下界高三个多数量级；锚点算子
要同时上控跨四个数量级的 HTC 范围与频率单元，Loewner 比率损失约六个数量级；修好需要按
参数单元 × 频率单元逐块 Gram，约 1e4 到 1e5 次稀疏求解。因此固定实频移版本保留，频率轴列为
未决问题。

## 采样、选点与富集路线

**B1 先验闭式点集（tensor Chebyshev、二维 Padua、嵌套 Clenshaw--Curtis Smolyak）**（PORT-STEP + PORT-FIXED-S；界太松）
完整闭式 coercivity 界要张量 63 阶（四千多个参数点）才能认证 0.1% 相对误差，换成广义特征值下界也只
降到 34 阶（一千二百多点）；而且该保证只对**未截断**快照空间成立，1e-3 SVD 既未计入证书也未再验证。

**B2 tensor corners（只用四个 HTC 角点）**（PORT-STEP；被反例证伪）
四角点的最坏误差比三个 log-Padua 点差约三十倍；角点响应张成更低秩的空间，并漏掉重要的混合方向。

**B3 log-Padua degree 2 与嵌套 level-3 Smolyak（加密确定性采样应带来单调改善）**（PORT-STEP；被反例证伪）
加密后误差反而翻倍、SVD 保留的模态数还更少；只有把 closing cutoff 收紧之后阶数与误差才一起改善。
失效环节是 closing SVD 压缩，不是采样族。

**B4 raw tensor Zolotarev 计数作为采样规模规则**（PORT-FIXED-S；界太松）
要达到同一档证书，Zolotarev 需要 4x4（16 点 / 64 RHS），而 Zolotarev-seeded certified greedy 只用
5 点 / 20 RHS 就够；同预算下 Padua 三点差一个数量级，十点到十五点还要好三到九个数量级。一维坐标的
Zolotarev 界不证明张量积满足每个 cross transfer 的相对误差。

**B5 Zolotarev-seeded weak greedy 的停止规则（有限候选网格证书）**（PORT-FIXED-S；被反例证伪）
选点本身很强（5 点 / 20 RHS 在数千点候选网格上给出 1e-5 到 1e-6 的相对证书，全阶解数从上百降到
二十）。被否掉的是"可把有限候选集上的最大值迁移成连续参数盒停止判据"这一说法：连续箱保证仍需在
对数坐标上的分支定界，且离线墙钟仍高于 stock。

**B6 seed + 排名最高的单个切角（2 个 HTC 点）**（PORT-STEP；被反例证伪）
holdout 最坏误差比 stock 差约五十个百分点量级；单角点只保护暴露边的一端。

**B7 seed + 三个切角（4 个 HTC 点）**（PORT-STEP；被反例证伪）
四点比三点更差，尽管两者最终阶数相同。压缩后的 SVD 空间一般不嵌套，**增加快照可以使误差上升**。

**B8 BDF1 输出残差界 greedy**（PORT-STEP + COST；界太松）
选择加提取的耗时是三点顶点规则的数倍，而误差界仍比容差高一个多数量级，无法在 1e-3 停止。

**B9 conditional Zolotarev 暴露边规则**（PORT-STEP + PORT-FIXED-S；被反例证伪，一维放置原理本身成立）
三点预算的 holdout 最坏 step 与 steady 都不过判据，其自身的有理界也远大于实际；两类设计的最坏误差
都出现在暴露端点，最小化一维 resolvent 比会把快照推离主导归一化输出的角点。

**B10 四顶点凸二次 majorant 作为选择规则 / 误差量**（PORT-FIXED-S；界太松，作选择规则有效）
它的特征值与种子处精确局部 Ritz Hessian 差三到六个数量级，且主方向相反；只对含 `X(p0)` 的
**未压缩**稳态快照空间成立，而交付空间不必含 `X(p0)`。作排序规则仍能得到可用的三点设计。

**B11 场残差 greedy（1x1 Zolotarev 种子 + 9x9 候选网格）**（PORT-FIXED-S + PORT-STEP；被反例证伪 + 界太松）
tol 1e-3 与 1e-4 两轮的 transfer 都只比 stock 改善一二十个百分点或同量级，且都**不满足每个 transfer
entry** 的容差，只有 nominal-power step 通过。

**B12 Zolotarev 2x2 种子 + 同样的场残差 greedy**（PORT-FIXED-S + PORT-STEP；被反例证伪）
两轮的 transfer 都劣于 1x1 臂，而 RHS 与时间更高。

**B13 固定 Zolotarev 4x4 张量替代随机 HTC 循环**（COST；成本不可行）
对 stock 只改善约十个百分点，却用约六倍 RHS 与约四倍提取时间。该次 1 mm 运行在极慢的瞬态角点参考
中被中断，声明不主张任何 1 mm 瞬态误差。

**B14 候选网格 17x17**（PORT-STEP；被反例证伪）
加密候选网格选出更少的 RHS，却给出更差的 holdout transfer；两种情况的最坏参数都是同一个物理角点。
**加密候选网格不改善输出误差。**

**B15 场残差 greedy + 收紧 closing SVD cutoff**（PORT-STEP + COST；成本不可行）
达标，但模态数几乎翻倍；介于两者之间的档位仍略超容差。决定性的是模态数，不是 HTC 放置。

**B16 稳态输出 greedy 直接用于动态四端口频移压缩 ROM**（PORT-STEP + PORT-FIXED-S + COST；成本不可行 + 被反例证伪）
它是那批运行中唯一在全 cutoff 下通过全部 step transfer 的臂，但最坏稳态 transfer 超容差近三倍；
最终 ROM 上的稳态网格证书在每个等 cutoff 行都失败，而原始稳态选择证书好三个数量级。
**原始稳态选择证书不是压缩频移 ROM 的证书。**

**B17 稳态输出 greedy + 17x17 候选网格**（PORT-STEP；被反例证伪）
最坏观测 step 略超容差，最终稳态网格证书仍差约五倍，大量候选未解决。即使通过的观测结果也对
候选网格敏感。

**B18 稳态输出 greedy + 收紧 closing cutoff**（PORT-STEP + COST；成本不可行）
阶数随 cutoff 收紧从四十几涨到近百；这些行改变了 closing 阈值，不构成与 stock 的等 cutoff 对比。
数据不支持小阶数、全输出保证的动态 ROM。

**B19 八组 HTC 的 17 点低频面设计**（PORT-STEP + PORT-FIXED-S + COST；被反例证伪）
有限时间目标通过，且比随机种子少约三十五百分点的解、快约三点六倍；但最坏稳态 entry 未过它自己的
1e-3 判据，且 `s <= 1/dt` 只是结构性假设。

**B20 八组 HTC：仅在单个 Zolotarev 种子处加 DC**（PORT-STEP + PORT-FIXED-S；被反例证伪）
三种设计里只有把 DC 铺满整个低频面才把稳态压到 1e-3 以下；只在种子处加 DC 时稳态仍差数倍。

**B21 多组数早期探索：全局稳态切向风险排名的 5 点，与欠分辨暴露面加密**（PORT-STEP + PORT-FIXED-S；被反例证伪）
低点数的全局面排名随维数升高而失效（从 4 组到 8 组误差升一个数量级）；欠分辨的七点面即便再加棋盘
格点仍差两个数量级。该组早期数据在一次 workspace 重置中丢失；这是证据质量注释，不是分类。

**B22 两组 Case 1：低频段三点面（80 解）与三切点铺满全部频移（144 解）**（PORT-STEP + PORT-FIXED-S + COST；被反例证伪）
三切点全频移版被低频面设计在 step 与 steady 上全面支配。暴露边只是有限几何采样规则，不是已建立的
二维 minimax Zolotarev 规则。

**B23 两组 Case 1：三低频点面 + 仅种子处 DC（84 解）**（PORT-STEP + PORT-FIXED-S；被反例证伪）
在验证集上看似达标，扩到更大的评估集就略超容差；三处全 DC 的版本在同一集合上还要差一个数量级。
**有限验证集不能当连续箱保证。**

**B24 1 mm 上用稀疏直接 LU 做谱准备与验证参考**（COST；成本不可行）
直接 LU 的总提取时间比 stock 更慢——谱准备一项就超过 stock 的全程——峰值内存为 GB 量级；换用
AMG-CG 逆作用后总时间降到低于 stock、内存降一个数量级，两种方法的节点值相对差在 1e-13 量级。
记录不把迭代逆声明为正式认证的谱包围。

## 压缩、缺陷传播与 inexact-moment 路线

**C1 inexact-moment 动态桥**（PORT-SYSTEM；被反例证伪）
代数核心在真实数据上被证实（两种形式十二位一致，与求积的相对差在 1e-5 量级），但**定理假设在交付基
上被直接违反**：交付列数大于源数使 X 秩亏，兼容缺陷达到 0.45（此时根本不存在满足 `F X = R` 的对称
`F`），且 H2 项要求的关键不等式在四个箱角全部失败三到五个数量级。

**C2 在交付基上实测桥量裕度（判决实验）**（PORT-SYSTEM；被反例证伪）
桥量在管线列数下无法便宜地变小（各相对量级从几十一直到 1e10 以上）；它本要刻画的压缩效应与交付 ROM
自身的 H2 误差同量级，无法分离。抽取循环实际执行的逐列残差判据比它想控制的块量低二到七个数量级。

**C3 LU cache 测量 bug（inexact-RK defect 记录的更正段）**（CORRECTION；测量更正）
原报告据此判"第一项就失败"，更正后同一角上的真实误差比交付 ROM 还好两个数量级。根因：一次运行只建
一个 cache，而分解只按 shift 值作键，于是第一个 HTC 点之后的所有点都在用别的点的分解；两个 bench
起初"相互印证"只是因为共享同一个 bug。

**C4 逐 shift 加性 defect 预算**（PORT-SYSTEM；界太松）
被否的不是第一项失败，而是**太松**：预算稳定高估联合缺陷 gap 一到一个多数量级、高估它本要界的交付
误差一到两个数量级；固定 `h` 下唯一既适定又占主导的项是 pre-SVD 到 delivered 的压缩。被否的只是
"逐 shift 加性聚合"，不是 defect-aware 桥本身。

**C5 active-set 原型：合成先行 + 真实 Case 1 验证**（COST；成本不可行）
合成部分只证明 operator sparsity，**不构成成本结论**。真实 Case 1 上过绝对阈值不保证同点相对容差；
相对目标那轮的端到端时间是 stock 的上百倍，且界未解决。

**C7 在未改动的 stock 最终基上对连续 HTC 箱做残差认证（零新增快照）**（PORT-FIXED-S；被反例证伪）
两个种子的多个端口在低 HTC 角全部超过容差（最差一个多数量级），而直接范数与 Gram 表达在同一批点上
一致到 1e-9 到 1e-11，说明违反不是约化求值的假象；未截断快照在同一探针上低两到三个数量级。
**生产 SVD 截断按快照方差而非方程残差排序，故任何只放在抽取之后的接受证书都不可能成立。**

**C9 低秩跨边界耦合（参数无关截断 SVD + 轴流形）**（PORT-FIXED-S + COST；界太松 + 成本不可行）
轴张成的精确恒等式在真实模型上被确认（相对差 1e-15 到 1e-16），低秩近似的局部 DC 传递误差很小；
但全局传递界本身在 1e4 量级，绝不能当 1e-3 认证，且形成参考 Green 块比 stock 随机抽取更贵。
前置诊断同时否掉两条近似路线：全箱居中 Neumann 比接近 1，使低阶全局 Taylor 场不适用；DC 场的
四角多线性插值在对数 HTC 审计下误差在 5e-2 量级，其全局 Bernstein 包络超过上角点阻抗 1e5 倍。

## 支撑诊断（不是失败路线）

**D1 span 内残差感知压缩 + 稳定的正交余量残差表示.** 正面部分：残差贪心在两个种子上都在较低阶数通过，
而 leading-SVD 要到六十几阶才首次通过；投影 QR 把与直接全向量残差的最大绝对偏差从原始 Gram 的
1e-8 到 1e-5 降到 1e-11 到 1e-13。代价与限制：阶数上升十几阶，基从约 0.37 MB 涨到约 0.52 MB；
最差残差在 Galerkin 富化下**不单调**；这只是离散诊断，不是连续箱证书，也不是原 Hankel / 冲激误差
定理——更强的方程残差判据**并不证明**会改善原 FANSTIC 动态界。

## 正文撤回（不是失败路线）

* **A9 误差目标的重估.** all-input 定义 `eta_E(p) = sqrt(lambda_max(E(p), E0))`、
  `E0 = (1/2) G^T C^-1 G` 是历史所用的归一化，不能无条件代入当前 `C` 加权动态范数；厂商的
  `2*eps` / `2*sqrt(eps)` 常数未核验原范数与归一化，当前不沿用。撤回的文档说法有两处：其一是
  "一个 Gramian 同时给出两个 all-input 指标"（`tr(D^T T D P)` 只给 `tr(E)`；先前的比值只测四个

  `THEORY.md` 与 `exact_error.py`；它的精确性不等于采样复杂度最优性，边界块逆作用必须计费。

## 交付量目标：代理量与富集路线

本节各条的目标量是 `THEORY.md` 的全场冲激响应端口范数 `epsilon_imp^2 = lambda_max(J(h;V), Q(h))`，
它**就是研究目标本身**（作用域 `PORT-SYSTEM`，不是历史口径），与 `THEORY.md` 命题 1 的
`D_fix = lambda_max(Delta, Y)` 之间没有已证换算（该缺口即 `THEORY.md` 的 P0）。本节条目全部在
5 mm Case 1 的同一个基上取得。

**E1 用能量 / POD 模态截断代理量驱动提取（`C`-度量冲激轨迹的 POD，按模态能量 `rho_i^2/(2 lambda_i)` 排序）**（PORT-SYSTEM；被反例证伪）
同阶时最坏交付缺陷比 stock 差**三个数量级**。两个结构性原因：`lambda_max(J, Q)` 取四个输入方向的
**最坏组合**，而能量判据对所有方向求和；源是局部形状，会激励 `rho_i` 大但折减能量小的快模态，
按能量排序恰好把它们丢掉——保留下来的模态只覆盖很小的 `lambda` 区间。**局部激励下模态截断是错的
子空间族**，这也是经典上换用 Krylov / moment-matching 族的原因。

**E2 把尾部方向 `C^-1 G` 当作交付缺口的富集方向**（PORT-SYSTEM；被反例证伪，前提失败；方向本身正确且相对列数免费）
加四列（列数增加约一成）只把最坏交付缺陷降约**九个百分点**。另有独立结果：`C^-1 G` 落在基内时
`omega -> infinity` 的极限项**精确归零**。两者合起来说明**尾部只占交付误差约 9%，其余约 91% 在中频**；
故前提"交付缺口在尾部"不成立，交付目标不能靠尾部富集达成。方向仍值得携带（中频富集无法替代它），
但它不是主要杠杆。

**E3 用固定实移证书 `D_fix` 驱动的提取器作为交付**（PORT-FIXED-S；被反例证伪）
一个把 `D_fix` 压到机器精度的基，其 `epsilon_imp^2` 仍是 O(1)，比 stock 差三个数量级。被证伪的是
"`D_fix` 认证的提取器即满足交付目标"，不否定固定实移目标本身的结果；需要补的正是 P0：
接受判据与富集见证点都要带动态内容。

本节三条的作用域边界：否定的是**代理量与固定实移驱动**，**不**否定固定实移目标本身已有的结果，
也**不**否定已经建立的构件——Woodbury 参考表、锚点 Riesz Gram、自适应对数划分叶子、Bernstein
控制矩阵包围都保留。需要替换的只有两样：**认证对象**与**富集见证点**，都换成 `epsilon_imp`。

## 先验界与度量错配路线

**F1 ratio-native Sylvester 桥 `epsilon_imp^2 <= D_fix + 2 eta_bar` 作为交付证书**（PORT-SYSTEM；界太松）
代数成立，且**在精确特征子空间上退化为等式**（两种独立算法吻合到十几个数量级，`eta_bar` 落到舍入
水平）。但在非不变空间上松弛**三到四个数量级**，而且证书驱动的富集几乎不动这个柄（十几步富集让
`eta_bar` 只动百分之几）。机理：`epsilon_imp^2` 经 `1/(2 lambda)` 权重由慢模态承载，而 `eta_bar` 是
`Q^-1/2 dS Q^-1/2` 的 Cauchy--Schwarz 界，在病态 pencil 上保留了缺陷自身的权重。唯一使 `eta_bar = 0`
的空间是特征空间，而它们给出 O(1) 的 `D_fix`。副产物：该桥把唯一精确且便宜的 `D_fix` 稀释成被
`2 eta_bar` 支配的界。

**F2 GPT 第一条锚点公式 `lambda <= ((sqrt(lambda_a) + tau_E)/(1 - tau_T))^2`（诊断版）**（PORT-FIXED-S；界太松）
公式本身正确（每个 cell 都压住远角真值），但松**三个数量级左右**，最宽的 cell 上 `tau_T` 接近 1，
证书几乎没有内容。细化 cell 上最伤的是 `tau_E`：投影误差在一个 cell 内变化约自身平方根的三分之一，
这是"锚定而不跟踪"的代价。

**F3 同上的严格版，用 `tau_T <= rho_cell sqrt(lambda_max(C, K_a)) norm(K_a^1/2 T_a q_a^-1/2)`**（PORT-FIXED-S；被反例证伪，度量错配，不是分辨率问题）
界的数值是 O(10) 到 O(100)，于是 `tau_T < 1` **在每个 cell 上都不成立**，严格版界全为 `none`；
界比实测高一个半到两个半数量级。机理：第三个因子是**刚度**范数却量在**质量**度量里
（`q_a = T_a^* C T_a`），与量级相反的 `sqrt(lambda_max(C, K_a))` 只部分抵消。要让界小于 1 需要
`rho_cell` 小到 1e-3 以下，远低于实测值。**证书必须在锚点 `q_a` 度量内从头建立，不能先在一个度量里
估计再换算回去。**

**F4 用 cell coercivity 常数 `rho_cell = max_cell norm(K_a^-1/2 dK K_a^-1/2)` 搭百分比级 cell 界**（PORT-FIXED-S；界太松，其代价结构另有成本问题）
`rho_cell` 本身便宜——每个 cell 一个广义特征值问题，且 `dK` 单调使最大值落在远角——但即便把网格
加密到数百个 cell，它仍停在 0.75 量级；按此推百分比级 cell 界需要每轴**一百到两百个 cell**。
另外 `rho` 随 cell 宽度**快于线性**收缩是 pre-asymptotic 现象，本质上最终回到线性。

**F5 用锚点形式 `norm(T_h - T_a)_a <= norm(dK T_a)_(a,*)` 取代 coercivity 形式**（PORT-FIXED-S；界太松）
"一步取代三次三角放大"是真的：锚点形式在每个 cell 上都赢过 coercivity 形式，倍数一到四。
但最紧也有两倍多、最松有三十几倍松弛，单靠 `T` 链条到不了百分比级。**更重要的结构信息：`T` 的真实
cell 变化本身就是 O(1) 到 O(4) 量级，即穿过 `T` 会丢掉 ROM 已捕获的大部分内容——证书必须建在投影
误差 `E` 上，不是 transfer `T` 上。**

**F6 用 Lipschitz 导数包络 `(norm(j') + lambda norm(q')) / lambda_min(q)` 作三个方向一致的证书**（PORT-SYSTEM；界太松）
包络本身随细化线性收敛（每加密一档 slack 降一档），但界比真实导数松一到三个数量级（困难方向接近
三个数量级）。根因是三角不等式**加上除以 `lambda_min(q)`**：换成沿最大化特征向量的精确 Rayleigh
导数后，同一配置的 slack 直接落到百分之几。**这条是后面对 F7、F8、F9 一连串度量错配的起点。**

**F7 gap 证书的导数形式 `abs(lambda'(t) - g0) <= R1 + 2 M0 eta/(gamma - eta)`**（PORT-SYSTEM；界太松 + 被反例证伪，尺子选错）
`R1` 比 `M0` 大**三到五个量级**，于是界比真值松三个多数量级。`H'` 本身经中心差分核验（相对差 1e-7
量级），所以不是实现错：`H'` 携带 `(B^-1/2)'` 的 Löwdin 权重，由近奇异 4x4 `B` 的逆平方根**逐元抵消**
主导；换成投影差也没有改善，因为锚点的主特征向量正是 `H'` 放大的方向。**结论：导数不是合适的尺子，
函数形式才是**——改成函数形式后界与真值只差万分之二。

**F8 用 `B_metric = norm(q^-1/2 (j' - lambda q') q^-1/2)` 作点态严格导数界**（PORT-FIXED-S；界太松）
它保留 `j'` 与 `lambda q'` 的抵消、去掉裸 `lambda_min(q)`（四维代价），在旧界本来就紧的地方确实紧
（一到两成），但在两个困难情形仍松**两个数量级**。GPT 的判决规则：`B_metric` 已接近 1 时，cell
严格化只是锚点相对余量包围；**只有 Rayleigh 值紧时，缺的是 top 特征方向的稳定性，不是算子范数**。

**F9 用标量化 `beta/alpha` 链条把锚点扰动界传到 `lambda`**（PORT-FIXED-S；界太松）
是严格上界，但松约**十倍**（等于该 cell 上锚点值的百分之八十几）。**松弛不在标量化**：`beta` 与
`alpha` 相对真实的 `max norm(S_B)`、`max norm(S_A)` 只松一到两成。真因是**把两贡献的范数相加再除以
`(1 - beta)`**。关键结构：真实的特征值展布比**每一个**单独贡献都小——`A` 与 `B` 的变化在
`H = B^-1/2 A B^-1/2` 上强烈抵消，任何分开取范数再相加的写法必然丢掉它。逐级收口是
`10.5 -> 1.65 -> 0.98`：换成判别式之差（`S_B` 项抵消掉一部分 `S_A`）再到沿锚点主特征向量的
Rayleigh 商，后者对真值的比值是 **0.984**。

**F10 transfer sandwich（SPD 锥上 operator convexity 上界 + reduced 变分原理下界）作为 1e-6 相对缺陷证书**（PORT-FIXED-S；成本不可行）
严格且不含 `m_b`，每个参数顶点只要 k 次全阶求解、顶点响应同时就是富集向量。但松弛**几乎全部来自
operator convexity 的弦误差**：把 trial 换成每节点精确 reduced solve 只能降低约四分之一。
弦误差按 `O(w^2)` 衰减（每对折约四分之一），压到 1e-6 需要把分片数再乘近三十倍，即整个 `h1` 轴上
上千个分片、顶点求解数进 1e4 量级。顺带说明：卡住 cell 上 Riesz 界与真值只差两三倍，
**上下角错配不是主要松弛来源**，"同步夹逼"最多换回一个小常数因子。

**F11 解 n 阶 KYP 的 SDP 来得到动态保证**（COST；成本不可行，无实测，属判决性降级）
没有实测数据；本条是明确指示：不要把 generalized KYP 当求解对象，只把它降级为 FDI 半负定判据的
等价性理论基础与独立校验，证书主线走可验证的导数 / 角点包络。按本文件惯例记"记录未给出"。

## 细化、采样与频率轴路线

**G1 靠细分采样网络把盒证书逼到 1e-3 一致**（PORT-SYSTEM；界太松）
八倍细化把 slack 打到**精确的 0**——因为角点最优 Temple 界总在自己的某个采样上取到该 cell 的最大值
——但界定"采样点之间"行为的余量只动了一点二倍。采样代价按每轴 `1/tolerance` 增长，而每八倍细化的
收益只有一点二，**采样网络给不出 1e-3 一致的盒保证**。副推论：停止规则应写在这个余量上而不是 slack
上，因为锚点取 cell 角点时 slack 按构造退化。

**G2 均匀细化（每 cell 一个对数区间）使 `rho_2 <= 裕度` 处处成立**（PORT-SYSTEM；成本不可行）
余量是 `O(Delta h^2)` 且用的是**参数绝对宽度**，不是对数宽度，所以"每个 cell 一个对数区间"在绝对
尺度上完全不等宽：父 cell 的比值超目标十几倍，下半个就降到 1 以下，上半个仍超十倍。局部指数在两段
之间从 0.5 跳到 1.6，单一幂律外推不可靠；按较陡的指数外推到含全局上确界的 cell 需要每轴数百个 cell，
而 `h2` 同样跨四个数量级，三维还要乘频率方向。**均匀细化不可行。** 但证书结构本身给出出路：`delta`
是**全局**目标，因此只有取到最大值的那个 cell 需要 `rho_2 <= delta - lambda_a` 这种紧条件，其余 cell
只要 `max_corner lambda_max + rho_2 <= delta`（用全局 `delta`，天然留有余量）→ 应改为自适应细化，
且 `rho_2 <= delta - lambda_a` 是数学条件而非人为阈值。

**G3 degree-1 多线性余量 + 全空间算子范数曲率 `sup norm(partial^2_ii F_delta)`，在粗 HTC cell 上不作细化直接使用**（PORT-SYSTEM，条件：粗 HTC cell；界太松）
该组合对中高 `h1` 的粗 cell 不成立：`Delta h1` 在几十量级时余量超裕度十几倍，中端在一百到两百量级时
超一百倍。而 `Delta h1` 在二十以内的 cell 通过（其中一档只差不到一倍的临界）。**否掉的是"粗 cell 上
无需细化即可使用"，不是 degree-1 方法本身**——同一条余量在细 cell 上是严格的，且角点律在实测的每个
cell 上无一例外（cell 宽跨三个数量级）。

**G4 曲率余量取范数形式 `sup norm(partial^2_ii F)`，或取 `lambda_max` 形式**（PORT-SYSTEM；被反例证伪，符号错）
Newton 余项是 `F - I[F] = -sum_i c_i partial^2_ii F`，系数 `c_i` 在 cell 上非负，故因子为**负**——
正确形式是 `rho_2 = sum_i (Delta h_i^2 / 8) sup_cell (-lambda_min(partial^2_ii F_delta))`，
**既不是 `lambda_max`，更不是范数**。范数形式普遍浪费两到三个数量级（中端实测超裕度一百倍），
`lambda_max` 形式把符号弄反；换成正确的 `-lambda_min` 后同一 cell 降到裕度的一半左右（改善约一百八十倍），三个 cell 全部通过。

**G5 直接用 `omega` 作频率轴的插值变量**（PORT-SYSTEM；被反例证伪）
在三维盒上**八分之零通过**，最坏界比 `delta` 尺度大约三个数量级，且最坏 cell **全部落在最低频**。
原因：`T(0) = K^-1 G` 与 `T(omega -> 0+) = C^-1 G/(i omega)` 不是同一个对象，`F` 在 `omega -> 0`
处有 `1/omega` 型行为，对它做多线性插值没有意义。换成倒数变量 `z = 1/omega`（`Tbar` 在 `z = 0` 正则，
端点是有限的 `-i C^-1 G`）后，低频那几个 cell 的界降了两个数量级，通过数从 0/8 升到 4/8，
且最坏 cell 不再位于最低频。

## 测量更正与实现坑

**H1 角点扫描里 `shares` 被同名循环变量遮蔽，导致第二个 cell 起只在自己的上角点求值**（CORRECTION；测量更正）
循环 `for index, (_, _, shares) in enumerate(loaded)` 重绑定了 `shares`——那是扫描前只建一次、长度为 2
的 cell 坐标数组；第一个 cell 之后它变成三元组，于是三重循环遍历该三元组的三个元素（都是 1），
**从第二个 cell 起每个 cell 只在 (1, 1, 1) 求值**。指纹在计数器里：报出的采样数是 `8 + 15 * 27`
而不是布局允许的 `16 * 8`；而当每 cell 采样数为三个分量时，真假 `shares` 长度相同、计数一致，
于是这个 bug 掩盖了整整一轮。因为上确界落在某个面上、而只有第一个 cell 采到了它，盒最大值低于
独立记录的角点值。此前观察到的"盒最大值低于独立记录的角点值"与"盒扫描不可复现"**都是这一个 bug：
不是物理、不是求解器**（点态探针本来就对，且与线程数无关）。把循环变量改名即修复，随后得到第一份
有效的完整盒证书。

**H2 推广到任意维后，二维路径静默地把频率当成 0**（CORRECTION；测量更正）
频率被写成"参数向量的第三个分量，若有；否则默认 0"，而二维路径传的是二元组，于是**静默按
`omega = 0` 求值**（即 `T(0) = K^-1 G`），命令行给的频率完全失效，而盒值本身看不出异常。
修复方式是**让缺失频率直接报错而不是静默默认**（同时由调用方显式写入频率）。修复后与修复前同一
配置逐位一致：`certified_delta` 与全部 per-cell 界都不变。**整个二维盒的结果在该 bug 之前取得，
不受影响**；受影响的那次二维运行已作废。

**H3 直接比较未绑定 basis identity 的 sup / floor / certificate 数字**（PORT-FIXED-S；实验不可比）
同一个探针点在不同容差下相差一个数量级，因为容差（`--tolerance`）**同时控制基构造与证书细化**；
同一个盒在不同容差下也差三个数量级。**这不是算错，而是比较对象不是同一个对象**：因此任何
sup / floor / certificate 记录都必须绑定 basis identity——至少同时记容差与阶数，最好还有 basis hash。
同时注意把容差设成 0 不能当"关掉细化"的开关：它会让基构造直接报错。

**H4 在虚轴复对称算子上套用 CG 或 pyamg 层次**（PORT-FIXED-S；被反例证伪，求解器类别错）
`A(h, i omega) = K + i omega C + sum h_i H_i` 是**精确复对称、非 Hermitian**。所有 CG 变体在迭代上限
内全部停滞（相对误差 O(10) 到 O(100)）：无预条件、Jacobi、实部 AMG 层次、正规方程层次都无效。
pyamg 的层次构造对复矩阵直接抛类型错误（其绑定只接受实数类型）。可用组合是**实 AMG 预条件的
GMRES**（实部 / 虚部分别施加，因为松弛过程拒收复向量），在低频到高频都收敛到 1e-11 量级；
`bicgstab` 在部分频率上无预条件直接 breakdown。**这修正一条常设偏好**：AMG 预条件 CG 是实 SPD
算子的正解，虚轴上对应的方法是 GMRES 或 BiCGSTAB；零频仍留给实 Riesz--Woodbury 机制。

**H5 交付量极小极大贪心的两个实现错**（CORRECTION；测量更正）
其一，富集用的 Gramian 权重写成对角的 `1/(2 lambda_i)`，正确形式是外积 `1/(lambda_i + lambda_k)`。
其二，"每步不降就停"必须改成 best-so-far，因为 Galerkin 富化下最坏交付缺陷**不单调**
（首步就可能上升），按单调停准则会在第一步就退出。

## 未闭合路线（不属于失败判定）

以下条目**证据强但尚未闭合**，它们描述的是成熟度与适用条件，不是"为什么被淘汰"。本节单独列出，
以免回看时把"只是还没证明"误当成"已经判死"。

* **角点律.** 在实测的每个 cell 上，角点上的量与采样最大值之比都精确等于 1（cell 宽跨三个数量级）；
  把整个二维盒当作单个 cell、只用四个角点求得的证书，与独立记录的全局上确界吻合到十五位。
  结构性理由是 `G_delta` 主项对参数**仿射** + 凸性 ⇒ 上确界在顶点。**但完整 resolvent 还含二阶及
  更高阶项**，一类含参数平方的逆映射没有现成的全局 operator-convexity 定理，ROM 误差项更没有，
  所以严格版本必须写成"角点 + 非仿射余量"。缺的正是二阶项 `Delta U^* Delta U` 的角点余量。
* **频率尾部用倒数变量 + `z = 0` 锚点.** `omega -> infinity` 的极限项已被独立验证为精确（与更早的
  数值观测一致到记录的位数；`C^-1 G` 入基时它应精确归零，实测也确实落到舍入水平）。但 `z` 方向的
  cell 细化规则尚未导出：三维上剩余的失败都在低 `h1` 的宽 `z` cell 上。
* **`r < 1`（Neumann 半径）.** 粗 cell 上不成立（实测到二点几），但细化后可达零点零几，所以它是
  **靠细化处处可达的条件**，不是结构性障碍；粗 cell 上需要谱下界 fallback。
* **`kappa_i` 里的采样因子.** `norm(U)`、`norm(U_E)` 仍取采样最大值；把它们也做成"角点 + 余量"形式
  （同为 `O(Delta h^2)` 结构、代价很低）之后，相应 cell 才算严格证书。
* **按方向取范数.** 待界量本质是 `x_a^* F x_a`，故建议做判决实验：在同一批中高 `h1` cell 上分别测
  `sup abs(x_a^* F'' x_a)`、`sup norm(P F'' x_a)` 与 `sup norm(F'')`。若前两个相对第三个真的小
  一到两个数量级，则 degree-1 可以保留，只需把余量从"算子范数曲率"改成"方向 + Temple 曲率"；
  只有这一版仍压不住才值得局部升 degree-2。优先顺序是**先收紧"取什么范数"，再提高"插值几阶"**。未跑。
