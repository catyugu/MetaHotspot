# BCI 宏模型提取：研究路线与证据台账（2026-10-17）

本文综合 MetaHotspot ChatGPT Project 中 2026-10-10—17 的多条探索对话，以及 `agent/work` 的 [THEORY.md](../THEORY.md)、[原失败档案](FAILURE_ARCHIVE.md) 和历史 [JFRGE 归档提交](https://github.com/catyugu/MetaHotspot/commit/56fbfea98a31b9a07c6553c41a23646f76faad54)。目的不是再列一个失败大全，而是给出**可追溯的证据、互不兼容的指标、当前决策与可复用构件**。2026-09-30 之前的大量旧路线仍只由原档案维护。

## 1. 证据等级与统一记法

- **A／仓库记录**：可定位到源码、历史提交和原始实验记录，但本次未重跑，不自动表明新的运行环境可复现。当前唯一细致核验到的数据集是 [JFRGE 的 METHOD](https://github.com/catyugu/MetaHotspot/blob/56fbfea98a31b9a07c6553c41a23646f76faad54/playground/jfrge/METHOD.md) 和 [PRODUCTION_REPORT](https://github.com/catyugu/MetaHotspot/blob/56fbfea98a31b9a07c6553c41a23646f76faad54/playground/jfrge/PRODUCTION_REPORT.md)；相应脚本、24 条 JSON 和环境说明均在该历史提交中，不在本分支。
- **B／Project 会话报告**：历史对话记有运行设置和数值，但本次未找到对应的、与 `agent/work` 配套的原始日志与复现脚本，**暂不能独立复核**。保留条件与数量级，不提升成正式生产验证。
- **C／机制或设想**：理论构件或后续设想；除明确引用了既有证明，不视为已实测优势。

**不同“通过”绝非一个事件。**

| 记号 | 实际验收对象 | 是否在最终交付空间 | 结论上限 |
| --- | --- | --- | --- |
| `RES-PRE` | 各输入 `V_j`、各既定实频移 `s` 的相对残差（欧氏或明确写出的 Riesz 版本） | 否（默认 SVD 前） | 指定抽样分布的固定频移残差风险 |
| `FIX-STATE` | `sup_w ||(X-X_V)w||_A / ||Xw||_A`，单实移或有限频移 | 取决于实际审核 `V` | 固定实移全输入场能量误差；不是 impulse |
| `IMP-FIELD` | `sup_w ||(T-T_V)w||_{L2_C} / ||Tw||_{L2_C}` | 需明确 | 全场 impulse 范数；离散参数抽查不等于连续盒保证 |
| `OBS-STEP` | 名义功率、指定端口或离散时刻的 step 响应 | 通常是 | 仅该观测与时间集 |
| `BOX` | 对所有 `h∈P` 成立的严格单元上界 | 需明确 | 确定性全盒，仍依赖证书的误差度量 |
| `PAC(μ,ρ,δ)` | 条件独立样本的序贯接受定理，错误接受概率至多 `δ` | 需明确审核阶段 | 以至少 `1−δ` 置信度得到 `Pr_{h∼μ}[失败]≤ρ`，**不是逐点 BOX** |

“连续域”必须带后缀：`BOX` 是每一点；`PAC` 是定义在连续参数分布上的风险。若控制量 `Φ` 只是固定实移残差，`PAC(Φ)` 不会神奇变成 `PAC(IMP-FIELD)`。原定频点与所有输入的联合失败事件可以共用一份风险预算；SVD 前独立空间的证书不能继承给 SVD 后交付基（除非另证压缩迁移）。

**比较规则**：同一热模型与 HTC 盒、输入空间、频移计划、误差控制量、停止标准、数值线性解精度、SVD 阶段及硬件环境；至少报告全阶逆作用次数 `N_FOM` 和含 AMG setup、投影、认证、SVD 的端到端墙钟。认证内部逆作用计入提取成本；独立研究 holdout 单列。除非另有证明，不能用快照数或离散通过率替代复杂度/连续风险保证。

## 2. 路线汇总与当前处理

| 路线（报告期） | 实验观察与边界 | 判断 / 证据 |
| --- | --- | --- |
| 旧确定性参数格点、角点、Zolotarev/弱贪心与局部 Bernstein 盒 | 某些有限网格误差很低，但连续停止不闭合、Gram/边界逆作用昂贵、或 post-SVD 后失效；旧档案有反例和计数更正 | **不作为提取主线**；固定 `s` 的 Riesz–Bernstein 数学工具保留（A/B，见旧档案） |
| 跨输入共享响应空间、切向 Krylov/失败点补方向（10-10/12） | 共享空间提取收益不明显且严重损伤 SVD 后精度；不能假设异质输入有共同低维响应空间。简单切向增量也未建立生产优势 | **否决共享空间主线**，逐输入独立富集（B） |
| 小模型认证引导选择（10-10） | 364 DOF、同一固定实移证书条件下，认证引导约 37–49 RHS、随机约 61–97 RHS；只是小模型、该指标的差异 | **线索而非新方法定案**，不能推广至动态与正式规模（B） |
| JFRGE 联合频移评价 + 随机/引导失败任务（10-12） | 47k/122k Case1 中，在**同样补足 `RES-PRE` 风险审核的 stock** 上有 RHS/时间收益；但仍慢于未加风险审核的原生产流程。算法不改频移，不共享输入空间 | **有条件正面、留作比较基线**（A）；不是 `IMP-FIELD` 或 post-SVD 保证 |
| 风险评分/贪心替代随机失败任务（10-13） | 225 DOF 上 AMG 评分约 97/99/96 个快照、随机失败点 102/98/104；评分额外成本且不稳定优于随机 | **不作为确定性贪心方案**，保留受控随机探索（B） |
| 方向性 block-Lanczos / Riesz 动态误差包围（10-13/17） | 小模型界可紧；40k–150k 成本与弱 HTC 收敛有障碍，详见 `4` | **有数学价值，尚非生产级廉价认证**（B） |
| shiftpilot、随机修复与风险反馈（10-15） | 64 DOF 多次少 RHS；144 DOF 初始严重退化，失败样本反馈可修复。固定频移风险未等价于时域 | **有反例，修复后仍待跨模型复验**（B） |
| PACS / 跨频移随机失败抽签（10-17） | 小模型少 FOM 却墙钟更慢；13,824 DOF、3 参数/3 异质输入有一次正面结果 | **局部正面，稳定性未知**（B） |
| SRG-PAC / 联合随机梯度富集（10-17） | 1,152–4,608 DOF 减少约 15.6% 逆作用；18,000 DOF 异质输入单组有收益；不过关的时域角点反例仍存在 | **固定频移风险候选；不是动态认证**（B） |
| 单次 V-cycle 近似响应替代求解（10-17） | 144/256 DOF 小样本节省全阶求解；18k/47k/122k 的默认容差对照不稳定，最大规模更慢 | **不单独作为主线**；松容差+选阶组合需另测（B） |
| 中间空间动态选阶 / 目标导向 SVD、冲激 POD（10-17） | 若有可接受中间基，目标感知选阶可改善某些模型；动态审计成本很高、未形成可迁移的连续域保证，旧简单目标导向 SVD 已被否决 | **研究构件，不作为已证高效的生产算法**（B） |
| 参数导数成组富集 | 常规 closing SVD 会挤掉动态重要方向；按相同最终阶数比较出现退化 | **否决直接成组堆入快照的配方**（B） |

术语中的“否决”针对上表**特定配方、指标和成本结构**，不是数学上否定整个 Lanczos、POD、Krylov、SVD 或随机法。原档案的 `PORT-STEP` 结论也不能直接升格为 `IMP-FIELD` 结论。

## 3. 可核验的正式规模证据：JFRGE（A）

数据来自 [2026-10-12 历史生产报告](https://github.com/catyugu/MetaHotspot/blob/56fbfea98a31b9a07c6553c41a23646f76faad54/playground/jfrge/PRODUCTION_REPORT.md)。`guided` 每轮 80% 概率选最大残差失败任务、20% 随机失败任务；`joint_random` 完全随机选失败任务。两者沿用原 `optimal` 频移、输入专属空间和 Ruge–Stuben AMG-CG。

| Case1 DOF | 比较范围 | stock（RHS / s） | guided（RHS / s） | 差异 |
| ---: | --- | ---: | ---: | --- |
| 47,085 | 5 个种子、同一 SVD 前风险闭环 | 161.00 / 29.125 | 132.00 / 25.660 | RHS −18.0%、总时 −11.9% |
| 122,400 | 3 个种子、同一 SVD 前风险闭环 | 173.00 / 86.474 | 141.33 / 70.704 | RHS −18.3%、总时 −18.2% |

认证对象为 `RES-PRE` **欧氏**相对残差，`ρ=0.05, δ=0.1`，审核抽样是生产 `_draw_h` 有效系数盒的对数均匀分布；**非物理 HTC 同分布声明**。风险补足的 stock 会多做一次已付费的默认 SVD/独立输入空间重建，故其时间偏慢，不能全部记为改进方法的算法收益。独立 holdout（47k 每方法合计 1000 点、122k 600 点）有 0–2 个失败，满足 5% 风险含义；它不是零失败的 BOX 证书。交付基采用生产默认 SVD，**不审核 SVD 后残差**；名义稳态/40 步阶跃诊断不代表全时域、任意输入组合。

此归档有 24 条原生 Case1 配对记录，但只有两个有效边界参数、几何具有对称性；另一个无对称算子的残差核单元核对并非新的大模型性能比较。历史计时在不同环境重跑前不能升级为通用收益。

## 4. 仅有 Project 对话报告的后续探索（B）

以下数字是**保留问题条件的研究纪要，不是本次执行的实验**；原始日志、基底哈希、容差/输入集合与完整代码版本必须补齐才能用于论文图表或正式量化结论。

**连续风险与低代价探索。** 10-15 `shiftpilot` 在 64 DOF 的 25 次小实验平均 RHS 从 68.20 降为 60.04，但 144 DOF 上候选失败率约 10.7%，stock 约 0.7%。随后使用压缩后随机见证点补方向，144/256 DOF 的报告失败率降到约 0.3%/0.2%；这是单独的有限样本观察。联合风险实验曾报告固定频移 850 样本、动态 650 样本的无失败/低上界；**动态标签依赖全阶特征分解**，没有可接受的生产规模认证成本证据。

**PACS / SRG-PAC 的两类单次好结果不应相互拼接。** PACS 的小模型（144–256 DOF）FOM 减少 35.9–58.8%，但完整墙钟约 5.9 s 对 3.9 s，仍**更慢**。另一组 13,824 DOF、3 参数/3 异质输入：随机跨频移失败任务调度 178→156 RHS、15.73→12.99 s、最终阶 159→140；只有一次有效配对。SRG-PAC 的 18,000 DOF、4 个不对称输入、23 个频移、`τ=1e-3`，报告 207→159 FOM、29.3→21.4 s；同样只是单组独立复核。这些审核是分布上的固定频移残差风险，不是最终全场动态 `IMP-FIELD` 风险。某一角点已出现代理残差通过而 impulse 超限的案例（见会话记录），因此不能把二者等同。

**Riesz–Lanczos：紧度与代价并存。** 10-13 的方向性 block-Lanczos 小模型 225 DOF 有 22/22 次有效包围，48 步最大上界/真实误差约 1.090；40k DOF 弱 HTC 的 128 步版本仍可能无法接受，150k DOF 单点评估约 2.69–10.60 s。10-17 的 Riesz 加权 6.4k DOF、160 步报告 12/12 可判决，指标区间约 0.00134–0.13844，但每点约 0.96 s 且有额外逆作用；10k DOF 约 2.5 s/点。普通 Lanczos、逆 Lanczos及 Gauss–Radau 其他实现分别存在界过松或每点约 6 s 的代价问题。**点态包围成立不等于便宜的连续分布风险抽样，更不等于有限预算内全盒证明。**

**单次校正与动态压缩。** 小模型单 V-cycle 近似方向曾减少昂贵的精确逆作用，但默认提取配置下没有稳定提速：47,085 DOF 的**候选 / stock** 为 7.78 / 6.95 s，122,400 DOF 为 28.56 / 22.62 s；18,073 DOF 的配对时间约为 2.07 / 2.16 s，差异很小，无法扭转大规模反转的判断。122,400 DOF 的另一**组合方案**（中间空间容差 0.02 + 动态选阶）报告中位构建/选阶 23.64→18.73 s，五种子均在有限的 16 参数点上通过 Riesz 全场核对、最大上界约 0.09254；**独立认证成本未包含**，是重建的 Python 规模原型，不是原生生产路径，更无连续风险证书。放宽容差但仍用原 SVD 的最大规模检查曾超限约 0.22，故不能把组合收益归功于“更松求解”单因素。

**SVD / 动态目标。** 400 DOF 的目标导向中间 ROM 优化（11 阶）曾在很小的验证集上把观察到的失败率从 77.5%–100% 降到 0%，优化约 4 s；它不是大规模端到端收益。121–144 DOF 的 impulse POD + 风险反馈曾得到 300 点中 0–4 个失败、报告风险上界 1.22%–4.14%，但审核约需 1,700–1,900 次 AMG-CG 逆作用，对照提取约 100 次快照。这些小样本利好不足以重新接纳早先否决的“简单目标导向 SVD 即可解决”的路线。参数导数成组富集在普通 SVD 后会挤占重要动态方向，同阶性能下降。

## 5. 当前可继承的核心构件，而非“已完成算法”

1. **独立输入空间与原频移**：保留每个输入的 `V_j`，不依赖源对称性；用原生产方法确定 `S_j`，不要靠改频移掩盖采样机制。
2. **联合残差的廉价评价**：JFRGE 的约化谱残差恒等式和稳定的 QR 表达可以在不增加 FOM 解的情况下评价多频移任务；不能免费忽略 QR/特征分解/内存。
3. **随机探索 + 失败反馈**：避免确定性最大评分造成的固定任务饥饿；若有序贯审核，冻结当前基、取新的条件独立样本，失败反馈训练，下一轮审核再抽新样本。认证嵌入循环而不是尾部装饰。
4. **Riesz 几何与误差指标一致**：实 SPD 上残差的 `A^{-1}` 对偶范数给能量误差；锚定逆作用与相对分母仍要界。复移位不可套 CG/实 SPD 证书，须另处理。
5. **压缩损失不能被抹去**：SVD 前风险只认证前一空间；若论文命题是最终动态 ROM，必须审查最终基，或给出严格可信的从中间空间到交付空间的迁移论证。允许仅报告 `RES-PRE` 结果，但标题和结论必须如实限定。

## 6. 面向下一轮正式验证的停止条件

后续不是再发明一个无比较的代理量，而是先冻结**用户接受的结果合同**：明确 `μ`、风险 `ρ`、置信失败概率 `δ`、被测空间、`τ`、全输入事件、动态/实移指标与数值误差预算；审查新旧控制量能否证明连接到最终 `IMP-FIELD`，否则只称代理指标。按 `THEORY.md` 的 PAC 定理给出统计结论，而非从有限 holdout 外推处处保证。

正式采用一种路线至少需要：数万及十几万 DOF、几何/边界/输入异质性、多个容差和种子；同一认证终止标准下与原 stock 及当前 JFRGE 分别配对；记录提取和认证的所有逆作用与完整时间/内存；独立报告 post-SVD 全场稳态与时域误差，尤其检查最坏输入组合、低 HTC、长时尾部；多次运行的中位数及离散度都呈正面，并确保精度没有退化。大型实 SPD 系统用 AMG 预条件迭代法，避免把 `splu` 当作生产基线。没有满足这些要求之前，**局部可行不是稳定更优，也不是学术创新已成立**。
