# 近期宏模型提取路线：问题与处理状态

本文件只梳理 MetaHotspot Project 近期研究路线的**核心缺陷、未决问题及处理状态**，不汇总实验量级、时间、误差、RHS、阶数或逐次结果。详细原始数据应留在各实验运行记录或 Git 历史中。下表既参考历史对话，也参考已有仓库材料；**未获得可追溯生产规模复现的路线，不写成稳定有效的结论**。

## 统一边界

- **RES-PRE**：默认 SVD 前，各输入独立空间在原定实频移上的残差；其风险认证不能自动转移到最终 ROM。
- **FIX-STATE**：固定实移的全输入、全场能量误差；不等于全场动态误差。
- **IMP-FIELD**：全场冲激响应的时间积分误差，需明确是在最终交付空间上衡量。
- **PAC**：给定连续参数分布、误差指标、风险阈值与置信预算的概率保证；不等于对整个参数盒逐点成立。

所有路线比较必须统一控制量、参数分布、输入空间、SVD 阶段、停止标准与完整端到端成本。认证应嵌入富集循环，不能把最后一次免费审核当作效率优势。

## 近期路线

| 路线 | 问题或失败原因 | 当前处理 |
| --- | --- | --- |
| **JFRGE：联合频移残差评价与随机化富集** | 对补齐同一 RES-PRE 风险认证的 stock 有条件优势，但对未经风险补齐的生产流程不构成公平胜出；重复 SVD 与桥接成本影响比较；不认证最终 ROM 动态误差 | 保留为有限口径的参考基线，不宣称普适胜出 |
| **联合频移共享响应空间** | 跨输入空间合并未获得稳定节省，且可能损坏最终 SVD 后精度 | 否决此共享空间配方，保留各输入独立空间 |
| **切向 Krylov / 切向富集** | 新方向不保证覆盖最坏输入组合；额外富集与检查成本未形成稳定的端到端收益 | 暂停作为主线 |
| **随机化联合富集** | 单次跨输入、跨频移共享富集会带入无效方向，最终压缩可能放大缺陷 | 不作为默认配方 |
| **贪心或评分驱动的失败任务选择** | 评分代价不低，最坏任务选择可能局部停滞；离散评分不提供连续域认证 | 不采用纯确定性贪心；随机探索可保留 |
| **PACS / 随机跨频移任务调度** | 局部减少求解不能保证墙钟收益；通常只针对 RES-PRE 风险，最终动态保真仍未覆盖 | 保留为待复验的调度候选 |
| **SRG-PAC / 随机梯度富集** | 个别模型有正面迹象，但尚缺异质模型重复验证；代理残差通过仍可能遗漏动态场误差 | 保留研究，不升级为完整宏模型保证 |
| **shiftpilot 与失败样本反馈** | 未经反馈时对某些模型失效；依赖事后修复，风险与训练成本可能转移 | 保留反馈思想，不采用单独选移规则 |
| **Riesz–Lanczos 动态误差包围** | 方向性误差包围可能较紧，但大规模、弱 HTC、连续风险审核时逆作用与迭代开销高；点态判决不等于全盒认证 | 数学研究方向，尚非廉价生产证书 |
| **单次 V-cycle / 低精度校正** | 便宜的近似响应不能确保高质量富集，较大模型上成本和精度收益不稳定 | 否决单独替代精确富集的通用宣称 |
| **放宽中间空间容差 + 动态选阶** | 组合收益难拆分，最终审核开销未闭合；放宽容差本身可能导致交付误差超限 | 仅作组合候选，需含认证的同标准比较 |
| **目标导向 SVD / 动态 POD** | 优化代理量与所有输入的最坏场误差不一致；动态标签及优化本身过贵，截断还可能丢掉重要方向 | 不接受简单目标导向压缩作为主线 |
| **参数导数成组富集** | 常规 closing SVD 按能量排序，导数方向可能挤占交付空间而不改善最坏误差 | 否决直接堆叠方向的配方 |
| **统一频移响应空间或多移位合并** | 共享响应空间提升有限，压缩后精度易退化；节约某类运算并非降低总成本 | 不作为当前优先方向 |
| **直接固定实移代理控制动态 ROM** | 固定实移小残差不能推出整个时间域的场误差，缺少匹配的传递定理 | 不得充当 IMP-FIELD 认证 |
| **动态风险联合认证** | PAC 抽样逻辑可成立，但若误差判别需大量全阶动态求解，认证成本会吞没提取收益 | 保留概率框架，另寻廉价且针对最终空间的控制量 |

## 2026-10-18 委托式调研轮

本轮把三个构件分别交给独立会话做文献、推导与原型，再由审阅方逐条核对口径。原型都在仓库外的独立目录里完成，模型是合成 SPD 热网络，求解用稀疏 LU（不是 AMG 预条件迭代），未在生产规模上复核，因此下面所有结论都只作**原型级**记录。

| 路线 | 得到什么 | 卡在哪 |
| --- | --- | --- |
| 最终空间的精确冲激误差恒等式 | 把动态误差的混合 Gramian 写成 `Q - Q_r + D_cross + D_cross^T`，其中交叉项按 ROM 极点分解为移位 resolvent 与 Ritz 残差；配套双侧括号的代数骨架。紧性在弱 HTC 与各向异性模型上最初严重崩坏，改用显式残差后恢复 | 复查确认：检查点重正交破坏三项递推后，由递推得到的移位残差**不是**上界（有代数反例：伪上界低于真值），因此那条紧性比例不能当作证据。改用显式 shifted 残差配合合法谱包围后，括号在精确算术下重新成立且紧性保住，但双精度下 Loewner 余量可以小到远低于浮点噪声，还缺外向舍入封装；单次审计成本在 Jacobi-CG 下仍显著高于提取 |
| 参数盒统一谱区间 | 对 PSD 仿射 Robin 族，盒上谱极值精确归约到两个相反角点的广义特征问题，角点上可给出后验双侧括号（不依赖 Ritz 收敛标志或安全系数） | 把区间标量化成 `beta/alpha` 再进入动态界会丢失方向信息：即使给出精确点谱与真实分母，也无法闭合容差。需要方向化 resolvent 或矩阵值信息，提高极端特征值精度没有收益 |
| 交付误差的嵌套单调性 | 只要交付空间真正嵌套，`Delta_V` 在 Loewner 序下单调、交付误差非增；最小 Riesz 残差上界对嵌套空间同样单调。并指出生产实现每轮对全部快照做全局重截断 SVD 才是"加快照反而变差"的根因，修法是追加式空间、SVD 只压缩新增方向 | 连续盒证书在低实移处过度保守（锚点失配 + 单元宽度），需要局部锚点与细分；共享锚点 Gram 的准备成本仍可能抵掉省下的快照；有限终止缺少廉价论证 |

**同时撤回一条口径错误的对比。** 把连续盒界同时强加给 stock 与候选，会制造虚假的效率差距：按 stock 原生 RES-PRE 连续合格停止后，其交付空间在最高实移处可以事后通过同一盒界，因此不能拿单实移的内部对比宣称提取效率优势。改成同停止准则后，联合共享空间只带来小幅快照节省，且有明显的独立风险退化，不构成稳定胜利。

本轮的三条路线都不足以改变主结论：仍没有在统一误差目标、统一停止准则与完整成本预算下稳定胜过 stock 的提取方法；可继承的构件是多移位 Lanczos 与极点分解、盒谱极值归约、以及追加式交付空间的单调性。

### 动态审计的成本：主要来自预条件器与移位分布，而不是逆作用次数

原先的"审计比提取贵一个数量级"是在 Jacobi 预条件下得出的。补做的同预条件器对照（同一 `rtol`、setup 计入、十万自由度量级、中等各向异性）显示：Jacobi 与 SSOR 下九次点态审计与提取相当甚至更贵；换成 IC(0)/IC(1) 或两层聚合预条件后，固定九次审计的成本降到提取的约三分之一到四分之三。但把审计对象换成**实际交付空间**（`r+1` 次逆作用）后，比值回升到接近甚至超过 1。原因不在右端：固定算子对照显示把功率源右端换成 Ritz 右端几乎不改变迭代数；差异来自所求解的移位算子分布（低移位稳态算子更难）以及提取侧可用的热启动。

这条结论的意义是双向的：点态审计在合格预条件下**不再是结构性的成本障碍**；但按 PAC 合同要乘以样本数，批量成本仍由样本数主导，是否可负担取决于能否用更少的样本达到同样的 `delta`。因此不应把"单点便宜"误读成"认证便宜"。

批量成本随后被实测，结论是否定的：一轮 PAC 验收要几百次参数依赖的全阶逆作用（逆作用计数本身与预条件器无关），双侧采用相同缓存政策后的端到端墙钟比在中型模型上是数倍、在十万自由度上是数十倍。这里有一个容易犯的比较错误被当场纠正：如果让审计共享预条件器而提取逐次重建，会得到一个虚假的"两倍"；把缓存政策对齐后，比值立刻回到数倍到数十倍。**因此动态 PAC 审计目前的合理定位是离线复核工具，而不是嵌入每次提取的生产停止条件。**

批量侧有一条容易被忽略的统计事实：换成随时有效的序贯推断（置信序列）并没有减少正面接受所需的样本数，在这组风险合同下反而增加；允许少量失败带来的灵活性，不等于更省样本。要突破这个成本结构，需要的是能**联合**评估多个 HTC 样本动态误差的廉价算法，而不是更换停止规则。

跨样本可合法复用的部分值得单独记下：稀疏结构与仿射分解、最终基与约化仿射 Gram、参数盒统一谱上下界（由 `H_i >= 0` 保证两个相反角点控制极值，一旦认证可被整批样本复用，且不要求 M-matrix 结构）、以及在重新验证残差前提下可复用的 SPD 预条件器。不能复用的是全阶 `B(h)^{-1}b`、各移位的 resolvent 作用、动态交叉 Gram，以及"ROM 已依赖过的历史验收样本"。

### 两个生产常数的经验校准

`probe_rounds`（每频移连续合格次数）与收尾 SVD 的截断阈值，都是历史遗留常数，从来没有被扫过。补做的两次扫描给出方向相反的两条结论：

- **`probe_rounds` 不能统一下调**。在二维导热板上把连续合格次数降到个位数会让冲激误差明显恶化；在部分双层网络模型上降低它却看不出差别。把次数加多能在个别模型上改善动态误差，但没有任何模型因此进入容差以内。所以这个常数是模型依赖的，不能用"更省样本"的理由全局调小，也不能靠加次数来弥补判据与交付目标之间的错配。
- **收尾截断阈值值得收紧**。在同一批快照、同一停止准则下把阈值从 `tau*sigma0` 收紧一档，模态数增加约一半，而交付的全场能量误差下降数倍；反向放宽则误差显著变差。代价是阶数上升，收益是交付质量，这是一个可以直接采纳的参数级改进。但需要同时记住：即便收紧到这一档，所有被扫过的模型仍然全部超过容差——**这说明瓶颈在判据，而不在参数**。

### 流程级的三条否定结论

- **放宽快照求解精度不划算**。把快照解的内部容差放宽一档，迭代数确实下降，但快照数随之大幅上升，最终阶数不变，交付误差可好可坏；再放宽一档会让随机检验出现零步停滞，RES-PRE 循环直接走不动。省下的迭代被"方向不准 → 更多重解"吃掉。
- **允许一次失败的统计接受规则没有收益**。这类规则的动机是提高样本效率，但实测既没有减少检验次数，也没有减少快照或端到端时间；交付误差可好可坏（在部分模型上明显变差），且全部仍超过容差。统计上的"允许失败"不等于工程上的"更省"。
- **增量压缩保住了嵌套性，但代价是界不紧**。把收尾压缩换成"旧空间冻结、新方向单独压缩"后，实测嵌套间隙与正交性误差都在机器精度量级，而全量重截断会真的丢掉旧方向（各向异性模型上出现过旧方向几乎完全不在下一轮截断空间的极端情形）。代价是增量方案的在线误差界成立但不紧，界与真值可以差一个数量级；因此它适合作为"保住单调性"的工程手段，不适合当作停止判据。

### 一个比标量谱界更有希望的方向化构件

上表第二条路线的失败说明标量 `beta/alpha` 进不了动态界，于是又单独试了一个**矩阵值**的替代：取 `M = B^2`、`Z = G`、`Y = B^{-1}Z`，在任意包含 `range(Z,Y)` 的正交子空间 `U` 上定义

```text
L_U(t) = Z_U^T (T + t I)^{-1} Z_U,   U_U(t) = Y_U^T T (T + t I)^{-1} Y_U,   T = U^T M U
```

则可证 `L_U(t) <= Z^T (M+tI)^{-1} Z <= U_U(t)`，证明只用 Galerkin 单调性与 `Z = BY` 的交换性，不出现 `lambda_min(B)`；频率积分保持 Loewner 序，最终给出 `epsilon_imp` 的双侧界。三个结构性质值得记下来：零频严格锚定 `U_U(0) = Z^T B^{-2} Z`、高频首阶矩正确（不会因为插入极小谱端点而虚假爆炸）、以及**认证子空间嵌套时括号单调收紧**（不必改动交付 ROM，可以原地加密认证空间）。

原型（`n` 在百量级）上初始上界/真值比约 1.1–1.25，加两层块 Krylov 方向后约 1.0–1.14，同样模型上传统谱端点 Gauss–Radau 八层是 6–9（极小 HTC 下 240–357）。但这只是紧性证据：成本口径、生产规模、以及"验收上界是否真的完全不含 `lambda_min`"都还没有定论，因此只记为一个待复核的方向化构件，不记作效率结论。

### 修复后的点态动态括号（替换那条被反例打穿的递推版本）

放弃递推残差之后，剩下的构造是：

```text
Q = Q0 + (1/2) R0^T B^{-1} R0,      Q0 = (1/2)(Z^T b + b^T Z - Z^T B Z),   R0 = b - B Z
Q0 <= Q <= Q0 + R0^T R0 / (2 alpha)
J = Q + Q_V - sum_j (c_j a_j + a_j^T c_j^T),   c_j = b^T (B + lambda_j I)^{-1} S_j
eps_lo = sqrt(lambda_max(J^- , Q^+)),   eps_hi = sqrt(lambda_max(J^+ , Q^-))
```

`J` 的上下界来自对每个极点的显式移位残差 `r = g - (B + lambda I) z` 与合法谱包围，不使用任何 Lanczos 递推关系。优点是它只依赖可以实际测算的量；缺点是每一环都要付逆作用的钱。

复核用两套独立参照（双精度稠密谱分解，与多精度重组 reduced 特征问题后回代求完整系统移位解），两套之间的一致性达到可支持到约 `1e-10` 的可信度；15 组点态实例的 Loewner 检查全部通过，名义上界与真值的差距在千分位以下。但把它当成"机器严格证书"目前不成立：在弱 HTC 上 `Q` 下界与真值之间的最小特征值余量可以小到远低于双精度噪声，实算里出现过负的最小特征值，把审核 CG 容差继续收紧反而使区间变宽。要升级成可用证书，必须先做外向舍入与区间线性代数这一层工程，而不是再改数学。

与之配套的成本观察：单次审计只需要个位数次右端逆作用，与提取的快照数同量级甚至更少；但迭代次数在 Jacobi 预条件下会被强各向异性放大一个数量级以上。因此这条路线是否"贵"，目前主要取决于预条件器，而不是逆作用次数。

### 零额外逆作用的连续单元证书（原型，尚未覆盖全部移位）

低实移下盒证书的贵，主要来自每个锚点的 `A(a)^{-1}G` 与 `A(a)^{-1}H_iV`。有一条绕开它的路子：不重新求逆，而是利用已有快照本身满足的平衡方程。设快照满足 `A(h_j) x_j = G b_j`，把这些快照及其组合整理成矩阵 `V, B, Z_i`，使 `K V + sum_i H_i Z_i = G B`（只需快照、稀疏乘法与小矩阵运算）。于是对任意满足 `BT = I` 的试验系数矩阵，残差可以精确写成

```text
R_T(h) = G - A(h) V T = sum_i H_i (Z_i - h_i V) T
```

再由 `A(h) >= sum_i h_i H_i` 得到

```text
R_T(h)^T A(h)^{-1} R_T(h) <= sum_i (1/h_i) T^T (Z_i - h_i V)^T H_i (Z_i - h_i V) T
```

右端完全保留残差方向，且**不增加任何全阶逆作用**；配 Bernstein 单元与 `1/h_i <= 1/a_i` 就能在连续盒上给上界。224–225 自由度、`s=0` 的原型上，单元加密到一定密度后名义上界进入容差以内，新增逆作用为零；在 12 组低实移案例中有 9 组闭合到容差以内。

两个必须记住的边界：其一，有一条反例说明仅靠 Robin 半正定项的主界存在超过容差的点态地板，无限细分也消不掉，此时必须引入 `K` 的能量贡献、增加真正有用的快照，或者退回昂贵的局部逆算子；其二，目前只覆盖 `s=0`，还不是生产原定移位集，因此"更少的快照数"不能直接换算成提取加速比。整条流程（随机探索 + 残差选点 + 零逆作用证书）在单个模型、单个实移上确实只需要个位数到十几次快照，但同任务对比尚未建立。

后续追问把这个构件的边界钉死了：把同一技巧按 `(1/h_i)` 与 `1/s` 分项放缩到 `s>0`，并在完整的 MPMM 移位集上逐移位核验，结果是不能闭合。原因分两层：一是被认证的冻结空间本身在低、中实移上就有独立真值超限见证（原生 stock 的最终 SVD 空间也在多数低、中实移上超限），这类空间不可能被任何正确的证书通过；二是即便换用允许 Robin 与质量项先抵消的更紧零逆作用对照，也只能让部分最高实移点态通过，剩余地板消除不掉。**因此"认证不花全阶逆作用"目前只在单实移上成立，不能推广成对完整移位计划的零成本认证。**
