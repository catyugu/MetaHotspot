# 确定性 BCI 参数采样与连续参数盒证书

本目录当前保留的是一套**确定性、可复现、带连续参数盒证明**的仿射 HTC 采样与
提取流程，以及它在原始两组 Case 1 上与 stock Extended-FANTASTIC 随机提取器的
受控比较。历史探索记录（包括已判定无效的方案及其原因）移入 `records/`。

代码（全部英文标识符与注释）：

```text

residual_certificate.py  A(h_min)-Riesz 逐点残差证书（供贪心选点使用）
certified_box.py         连续参数盒证书（本目录的核心新工具）
deterministic_design.py  确定性选点与快照组装

```

## 1. 问题与基线

被提取对象是仿射 HTC 族 `A(p) = K + s*C + sum_i p_i H_i`（`H_i` 半正定，
`0 < p_low <= p <= p_high`，四个共址源/结温端口）。基线是 stock
Extended-FANTASTIC（`metahotspot.macromodel.utils.build_parametric_basis`）：

* 每个源、每条频移按 MPMM 椭圆匹配点求解；下一个 HTC 参数按对数均匀**随机**抽取，
  连续 `probe_rounds` 次残差检查通过后推进；
* 全部精确响应做**列归一化 SVD**（相对截断 `1e-3`），再补常向量。

它的两个缺陷都是结构性的：快照集依赖随机种子；有限次随机探针通过不等于连续参数域
上的最坏情形结论。记录中的实测尾部（`records/RESULTS.md`）：三个参数点时十个种子给
出 `0.0047% / 0.094% / 4.40%`（最小/中位/最大）的结温误差。

基线的全阶求解次数不依赖我们替它选的探针轮数：2.5 mm 上 `probe_rounds` 取生产
默认值 `3` 时两个种子给出 128 / 126 次精确求解，取 `5` 时给出 130 / 124 次，
本目录使用的 `10` 给出 126 / 127 次。下文的求解次数比较不是靠调大基线的
`probe_rounds` 得到的。

## 2. 结果摘要（2.5 mm，9072 单元，4 个源，dt = 50 s，40 步 BDF1）

同一验证集（4 个物理 HTC 角点 + 36 个固定种子对数均匀参数，共 40 点），
逐项误差按**同一参数**的精确稳态结温传递归一化：

```text
设计                    全阶求解 算子分解    ROM 阶  最坏步进项     最坏稳态项
确定性 3 点 (本方法)    92       23          45      1.226e-03      6.705e-04
stock, seed 20260805    126      126         42      1.757e-03      6.092e-03
stock, seed 7           127      127         42      1.924e-03      6.770e-03
```

连续参数盒证书（1024 个对数单元、三阶 jet、4x4 锚块，1024 个角点直接解，
每个基约 65 s 验证开销，**不增加任何提取阶段的全阶求解**）：

```text
设计                   证书(对角归一)  证书(逐项归一)  证书(绝对, K/W)
确定性 3 点              1.892e-05      1.050e-02      1.972e-05
stock, seed 20260805     4.737e-05      1.334e-02      4.967e-05
stock, seed 7            6.222e-05      1.513e-02      6.524e-05
```

结论：

1. **求解次数更少**：内核里只分解 23 个不同的稀疏算子（每个算子一次分解，四个
   端口在这同一次分解上各解一个右端，共 92 次右端求解），基线是 126/127 次
   AMG-CG 求解、每次的算子都不同且每次都要重建一次 Ruge--Stuben 预条件。以右端
   计减少约 27%，以算子分解计减少 5.5 倍。同时实测最坏步进误差低 1.4--1.6 倍、
   最坏稳态误差低 9--10 倍。
2. **首次给出连续参数盒保证**：对**盒内每一点**，交付基底的稳态结温传递误差不超过
   表中数值；同一套证书套在基线基底上也成立，但更松（对角归一 2.5--3.3 倍）。
   基线本身无法给出任何这类结论。
3. 证书是**交付后的事后验证**：与基底来源、SVD 截断、ROM 阶数无关；可以在截断阈值、
   参数点集合之间做取舍，而不产生一次额外提取求解。

## 3. 新方法

### 3.1 确定性选点

三个阶段，全程无随机数：

1. `zolotarev_seed`：对每个 HTC 群，用 Krylov 极值特征值迭代给出该坐标的广义谱区间
   `spectrum(A_minus, H_i)` 的**外包**，再用有限区间 Zolotarev 规则取一个内点。该点
   是一维核 `1/(lambda + p)` 的极小极大有理插值节点，误差有闭式界
   `4*exp(-n*pi^2/log(16*gamma))`。
2. `certified_greedy_points`：在确定性的 41x41 对数网格上，按 `A(h_min)`-Riesz
   残差**证书**取最大者作为下一个参数（弱贪心）。每个候选点的得分都是该点传递误差的
   上界，停止条件因此是确定性的有限候选陈述，而不是“随机探针连续通过”。
3. `build_basis`：**所有端口共用一份** MPMM 椭圆频移计划。椭圆规则的闭式误差界
   只要求谱区间包含该端口的广义谱，四个端口区间的并集对每个端口都成立，所以一份
   计划对每个端口都是合法计划。低频移（`s <= 1/dt`）使用全部已选参数，高频移只用
   种子点，另外在全部已选参数上补 `s = 0`（稳态）端点，最后做**未经改动**的列
   归一化 SVD（`1e-3`）+ 常向量。每个 `(频移, 参数)` 算子只分解一次，四个端口在
   这同一次分解上各解一个右端；选点阶段已经求过的驻定（`s = 0`）响应块经同一个
   缓存直接充当稳态端点。

2.5 mm 上选出的三点为有效坐标 `(346.03, 14.53)`、`(1.00, 234.38)`、`(9285.71, 0.996)`；
贪心证书依次为 `inf -> 4.889e-02 -> 6.662e-03`（第 3 点后触发预算停止）。
每端口 12 条频移中 4 条为低频移，故 `4*(4*3 + 8) + 4*3 = 92` 次右端求解，
分布在 `4*3 + 8 + 3 = 23` 个算子上。

### 3.1.1 计划必须按族而不是按端口生成

四个端口的谱区间估计在 15 位有效数字上一致（`lambda_max` 相差 `2.8e-14`），但按
端口分别生成频移会让 12 条频移中的 11 条因最后一位差异而变成不同的算子，同一个
矩阵因此被分解 2--3 次。改用并集区间的一份计划后，交付的基底与按端口分别取计划
时**完全一致**（同一份快照矩阵、同一个证书值 `1.892e-05`），但 2.5 mm 上的稀疏
分解次数从 42 降到 23，5 mm 上从 32 降到 22。频移计划与 HTC 参数设计都是**算子族**
的属性，不是某个源端口的属性。

### 3.1.2 HTC 参数点数是成本选择，不是收敛判据

把预算放开，贪心会在第 5 点把选点证书降到 `1e-5` 以下（2.5 mm，
`inf -> 4.889e-02 -> 6.662e-03 -> ... -> 4.844e-07`）。同一 40 点验证集上的
实测代价与精度：

```text
参数点                  全阶求解 算子分解    ROM 阶  最坏步进项     最坏稳态项
2                       72       18          43      1.849e-03      1.952e-02
3                       92       23          45      1.226e-03      6.705e-04
4                       112      28          45      1.292e-03      2.017e-04
5                       132      33          45      6.459e-04      2.339e-04
stock 20260805          126      126         42      1.757e-03      6.092e-03
```

步进误差对参数点数**不单调**（压缩后的 SVD 空间不嵌套，见
`records/POST_SVD_EFFECT.md`），所以交付默认停在 3 点：它在两项计数上都少于基线
（92 < 126 次右端，23 << 126 个算子），两项实测误差也都更低。需要更准时可以按
上表选 5 点，代价是右端求解次数比基线高约 5%。

### 3.2 整盒证书：命题

固定实频移 `s >= 0`、交付基底 `V`（列正交，来源不限）、盒 `[p_low, p_high]`。记

```text
A(p)   = K + s*C + sum_i p_i H_i
X(p)   = A(p)^-1 G
X_V(p) = V (V^T A(p) V)^-1 V^T G
Y(p)   = G^T X(p),   Y_V(p) = G^T X_V(p)
```

则对**盒内每个 p** 与每个端口对 (a,b)：

```text
|Y_ab(p) - Y_V,ab(p)| <= B_ab := sqrt(D_a D_b)
D_a  = max over Bernstein nodes of  [ block^T Gram(anchor) block ]_aa
```

其中 `Gram(anchor) = Z^T A(anchor)^-1 Z` 是残差张成空间
`Z = [G, (K+sC)V, H_1 V, ..., H_d V]`（列数 `(d+2)m + k`）在锚点处的 Riesz Gram。
相对形式再除以**同一参数**精确稳态传递的下界；由 M-矩阵单调性
`dY_ab/dp_k = -x_a^T H_k x_b <= 0`，单元上角点的精确传递即该下界。

### 3.3 证明

1. **Galerkin 最优性**：`X_V(p)` 是 `X(p)` 在 `range(V)` 内的 `A(p)`-能量投影，故对
   *任意*试探系数矩阵 `q(p)`，`r_q(p) = G - A(p) V q(p)` 满足
   `Y(p) - Y_V(p) = r(p)^T A(p)^-1 r(p) <= r_q(p)^T A(p)^-1 r_q(p)`；且
   `Y - Y_V` 半正定，故非对角项被 `sqrt(对角_a * 对角_b)` 控制。
2. **Loewner 单调性**：`H_i` 半正定、`p` 不低于锚点，故 `A(p) >= A(anchor)`、
   `A(p)^-1 <= A(anchor)^-1`，于是加权残差范数被锚点 Riesz 范数上控。
3. **可计算化**：取 `q(p)` 为**小系统**
   `(V^T A(p) V) a = V^T G` 在单元中心的 Taylor jet。于是 `r_q` 是多项式，其分块系数
   落在固定张成空间 `Z` 内；多项式在单元上的张量 Bernstein 系数是凸组合，因此 Gram
   二次型在该点的值不超过系数逐个取值中的最大者——这一步给出**整单元**（而非单点）的界。
4. **归一化**：由 3.2 的单调性取单元上角点精确传递作分母，即为同参数相对误差上界。

全部步骤只需一次锚点稀疏分解与 `span_columns` 次稀疏回代；单元上的评估是小系统稠密
代数，与模型规模无关。把单元数、jet 阶数提高不产生任何新的全阶求解。

### 3.4 成本与实测紧度

* 2.5 mm：每个基底 4x4=16 个锚 Gram + 1024 个角点直接解，约 65 s；其中没有一个
  是提取阶段的 AMG-CG 求解，全部是固定算子的直接稀疏分解。
* 提取阶段本身：92 次右端求解由 23 个不同的稀疏 LU 分解提供（四个端口共用一份
  频移计划，每个算子只分解一次），2.5 mm 单线程约 1--2 s；基线的 126 次 AMG-CG
  求解每次都重建预条件，同机约 3 s。
* **上界性质经审计**（5 mm，256 单元、三阶 jet、每单元 25 个随机内点，共 6400 个
  全阶对照解）：没有任何单元出现 `证书 < 实测`；全盒最大实测绝对误差 `5.531e-03`
  与其所在单元的证书 `5.622e-03` 相差约 2%。单元级比值可以到数百倍（该单元自身误差
  极小），逐点比值则只有 1.1--5.7（2.5 mm，10 余个分布点）。
* 21x21 审计网格上，五点原始张成空间的最坏同参数逐项相对误差为 `3.173e-06`
  （与 `records/ZOLOTAREV_RESULTS.md` 记录一致），说明证书给出的是同量级的保守界。
* 缩放（5 mm）：单元 256/1024/4096 时对角归一界 `3.07e-3 / 6.14e-5 / 7.28e-6`，
  随细化稳定收敛；4096 单元三阶 jet 耗时 10 s。逐项归一界在 4096 单元饱和于
  `~4e-3`，因为最弱耦合项的自身分母比自热结温小约三个量级——逐项归一化是三种归一
  中最弱的一种，报告里同时给出对角归一与绝对量。
* 证书对基底有区分力：同一设置下基线基底的界比确定性基底松 2.5--3.3 倍。
* `shift = 1/dt` 时同一套证书覆盖 BDF1 递推所用的算子族（`test_shift_certificate_
  covers_the_shifted_family` 在玩具族上验证 `bound >= 实测`）。

## 4. 已验证无效的方案及其原因

以下每一条都在本仓库真实运行过，细节与数字见 `records/`（部分脚本已按本次清理删除，
记录中保留了命令与结论）。

1. **直接套用 holomorphy + 张量 Chebyshev 的 a priori 保证**：数学上成立，但 2.5 mm
   Case 1 在四十年 HTC 范围上的 coercivity 估计需要 63 阶（4096 点）；即使换成广义
   特征值下界也要约 34 阶（1225 点）。而且压缩用的 `1e-3` SVD 会直接破坏该保证。
   结论：不作为生产规则。
2. **固定 CL / Padua / Smolyak 点集 + 原 SVD**：去掉随机种子，但二阶反而比一阶差
   （`0.092% -> 0.194%`）——SVD 按经验奇异向量重新加权，压缩空间不嵌套。采样族不是
   非单调性的原因，压缩才是。
3. **局部参数盒 Taylor/Bernstein 证书**：证明正确但覆盖范围极小（一阶仅 ±0.25%，
   二阶 ±2%，三阶 ±5%，四阶 ±10%，2.5 mm），且每个盒都要全阶中心轨迹与灵敏度；
   全局多项式-矩阵分式 Bernstein 不等式仍给出 ~700 的无用界；2.5 mm 的 ±1% 局部证书
   要 246 s 且先差 12%。结论：只作诊断，不作采样策略。
4. **Neumann/多项式全局界**：全局中心化 Neumann 比 `q = 0.9974`（5 mm）/
   `0.9977`（2.5 mm），需要约 2600--3000 阶；四角多线性 DC 插值相对误差 `5.1e-2`；
   全局 Bernstein 传递包络大于 `2e5 倍`上角点阻抗。结论：全部不可用。
5. **低秩跨边界耦合**：几何上交叉块确有 4 个主导通道（实测），但（a）算出参考 Green
   块本身需要 280--1072 次边界求解，多于随机提取；（b）可用全局传递界为 `1.0e4`--
   `1.3e4`；（c）精确轴张成定理成立在有限轴采样与 `1e-3` SVD 之前。
6. **BDF1 输出残差证书（K_min^-1 全局 Gram）**：界 `7.08e-2` 对实测 `1.76e-3`；换成
   局部 `K(p)^-1` 仍有 `2.1e-2 / 3.1e-2`。40 步累积（几何和约 38）使它无法在 `1e-3`
   停。结论：需要更强的试解，未完成。
7. **切向角点四顶点规则**：四顶点极值化本身是合法原始空间界，但其数值极悲观
   （缩放二次型 `8.6e4` 对实测 `2e-4`）；把它当选择规则得到的 3 点设计实测很好
   （2.5 mm 步进 `6.19e-4` 对 stock `1.76e-3`），但没有证明。
8. **条件 Zolotarev 边缘布点**：一维原始 resolvent 比值最小化会把快照推离主导归一化
   输出的角点，实测 `1.855e-3` 对端点规则的 `6.189e-4`。结论：弃用。
9. **17 点低频面 + DC（8 组）**：实测优于 stock 且求解更少（372 对 466），但“暴露面”
   是经验选择，四维修正余项缺失；且不加 DC 时稳态判据不过（`4.58e-3`）。
10. **聚合脉冲能量代替最坏输入**：`tr(E)` 会掩盖同时激励下的最坏线性组合；
    `(100,100)` 处差异约 0.28%，必须用 4x4 广义特征值。
11. **本次新验证的负结果——频率轴（Hankel）整盒证书**：把 3.2 的锚定 Riesz 论证搬到
    `W(p,omega) = A(p) + omega*C` 上，实测（5 mm）传递误差上确界 `5.81e2`，而整模型
    Hankel 下界仅 `0.185`，相对界 `3.1e3`——完全无用。原因是锚点 Riesz 算子必须同时
    上控整个 HTC 范围（四个数量级）与频率单元，Loewner 比率损失约六个数量级。要修好
    需要按 (参数单元 x 频率单元) 逐块 Gram，即约 10^4--10^5 次稀疏求解，不经济。
    因此 `certified_box.py` 只保留固定实频移版本，频率轴明确列为未决问题。
12. **本次新验证的负结果——用整盒证书挑选截断阶数**：把 3.2 的证书扫到同一快照
    矩阵的不同截断阶数上（5 mm，8x8 单元、二阶 jet、2x2 锚块、共享频移计划），
    对角归一界从 11 阶的 `5.605e-01` 只降到 41 阶的 `5.221e-01`——几乎不随阶数
    变化。原因是这个界被锚点的 Loewner 损失主导（同一设置下实测误差比界小 3--5 个
    数量级），而不是被交付基底自身的精度主导。结论：证书不能在截断阈值之间做
    取舍，`1e-3` 的相对截断必须保持为固定的生产设置。

## 5. 复现与验证

* 16 个语义测试全部通过（0.3 s）：Bernstein 包络、Zolotarev 闭式界与节点、
  每群谱区间外包、逐点残差证书、单元界上控实测误差、分母单调下界、细化收敛、
  平移算子族覆盖、贪心可复现、求解计数、共享频移计划与选点/提取之间的缓存复用。
* 驱动程序在 5 mm 与 2.5 mm 上跑通：设计、两个 stock 种子、三个基底各自的证书、
  40 点全阶步进/稳态验证，以及可选的全阶审计。
* 全盒审计复核（5 mm，256 单元、三阶 jet、每单元 25 个随机内点 = 6400 个全阶参照

## 6. 局限与未决问题

1. **未认证的量**：40 步 BDF1 轨迹误差与频率轴（Hankel、脉冲能量）只有实测；
   证书覆盖的是给定实频移（`s = 0`，以及 `s = 1/dt` 的算子族）的稳态传递。
2. **浮点**：所有不等式在实数域精确成立；稀疏分解、Gram 与稠密求解是普通浮点，
   报告中显式给出 `floating_point_certified=False`。要做成计算机辅助证明需要
   外向舍入的区间线性代数。
3. **逐项归一化仍偏松**：弱耦合项的自身分母很小，逐项相对界在 2.5 mm/1024 单元
   为 `1.05e-02`；对角归一与绝对量已到 `1.89e-05 / 1.97e-05`。
4. **选点最优性**：种子点有单变量极小极大依据，后续点只是确定性贪心，没有
   多维最优性证明。
5. **未做**：跨网格（1 mm）证书、更多 HTC 分组下的证书。**已作废**：把证书闭入
   截断阈值搜索（用证书挑选最小合格 ROM 阶数）——见 §4 第 12 条，该界对截断阶数
   没有分辨力。
