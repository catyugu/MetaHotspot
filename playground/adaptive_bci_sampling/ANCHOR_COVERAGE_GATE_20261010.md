# 单快照参数覆盖与同输入残差见证：2026-10-10 判决

本轮回应的问题是：一次提取求解能否产生有用的参数覆盖区域，进而让
认证直接参与提取，而不依赖共享响应空间或全域贪心搜索？

结论：**单快照的廉价局部覆盖失败。同输入多个快照的仿射残差见证在
稳态有用，但本轮扩展到原移位计划的原型未减少提取成本，尚无全时间
阶跃证书，不升级为新的提取算法。** 这是指定构造的判决，不是所有
参数覆盖方法不可行的证明。

实现入口为 `anchor_coverage_gate.py`。所有全阶提取均为 AMG-CG；各源
始终拥有独立快照空间。跨源只在原算法式的末尾拼接和 SVD 时出现；末尾也按生产约定保留常数模态。
没有共享空间选点，没有新增单元测试，也没有修改生产 `utils.py`。

## 1. 模型、指标和成本作用域

- Case1 的 364 自由度矩阵重构，网格参数 10 mm，四输入、两个不重叠的
  Robin 对角边界。当前重构未与原生装配独立核对。
- 有效 Robin 系数各维独立 log-uniform；端点分别约为
  `[0.9999923, 9285.7143]` 和 `[0.9836066, 59.6421471]`。
- 证书针对单输入、固定实移位的响应相对 `K(h)+sC` 能量误差，容限
  `1e-3`。这不是动态全场 `C` 范数误差，不覆盖任意输入抵消组合。
- 精确算术下证明有效；实现计入真实 CG 缺陷，但未使用外向舍入。
- 每次求解一个输入右端。一次共同 Collatz 辅助求解也单独报告。
  它不随候选参数或基向量数增长。
- 稠密求解和谱分解仅用于小模型独立参考，不能算作生产证书的免费工作。
- 生产随机基线由现有 `probabilistic_extraction.stock()` 原样调用并捕获
  SVD 前快照。其随机三次通过规则与本轮能量证书检查**不是同一验收条件**；
  不能把下面的 RHS 对照解释为同保证最优性定理。

## 2. 一个快照的廉价证书

设

$$A_s(h)=K_0+\sum_i h_iH_i+sC,\qquad K_0\succeq0,\quad C\succ0.$$

`H_i` 是非负、互不重叠的对角边界。取锚点快照 `v`，保留实际缺陷

$$d=g-A_s(h_c)v.$$

一次共同辅助求解得到正向量 `z`，并检查

$$\alpha=\min_j\frac{[K(h_{\min})z]_j}{[Cz]_j}>0.$$

对于本模型的不可约对称热 M-matrix，Collatz–Wielandt 给出
`K(h) >= alpha C`。正性和实际矩阵乘积都检查；不用 Ritz 最小值替代下界。
因此 `A_s(h) >= (alpha+s)C`。

残差分成边界变化和求解缺陷：

$$r(h)=g-A_s(h)v=d+\sum_i(h_{c,i}-h_i)H_iv.$$

令 `T_i=v^T H_i v`，利用 `A_s(h) >= sum h_i H_i` 及边界支持性，

$$\|r(h)\|_{A_s(h)^{-1}}
\le \left(\sum_i\frac{(h_{c,i}-h_i)^2}{h_i}T_i\right)^{1/2}
+\frac{\|d\|_{C^{-1}}}{\sqrt{\alpha+s}}=:\sqrt{B(h)}.$$

其中 Robin 对角矩阵在内部为零。这个不等式通过残差对偶范数的变分表达
证明，**不能对整个空间直接把它当可逆矩阵**。

再计算试验向量的能量下界

$$q(h)=2g^Tv-v^TA_s(h)v.$$

若 `q>0`，对于任何仍包含 `v` 的 Galerkin 空间，

$$E_V(h)\le\sqrt{\frac{B(h)}{q(h)+B(h)}}.$$

证明：精确响应 `x=A_s(h)^{-1}g` 满足
`||x-v||_A^2=||x||_A^2-q`；Galerkin 最佳能量逼近的误差不超过试验向量误差。
在 `q>0` 时，`b/(q+b)` 关于 `b` 单调，代入对偶残差上界即可。
`q<=0` 返回无法认证。基扩充保持见证向量时，区域继续有效；SVD 删除
见证向量后，该结论不能自动沿用。

本证书预计算每个边界的一项标量 `T_i`，查询成本 `O(p)`，没有逐参数
全阶逆作用。

### 可计算概率质量的对数盒

在 `|log(h_i/h_c,i)| <= r` 的区域中，设 `P=sum h_c,i T_i`，有

$$\sqrt{B}\le e^{r/2}(e^r-1)\sqrt P+
\frac{\|d\|_{C^{-1}}}{\sqrt{\alpha+s}},\qquad
q\ge q(h_c)-(e^r-1)P.$$

由该上界解半径 `r`，与原盒相交后，概率质量是各轴对数宽度比之积。
这是连续区域证书，不是把有限参数点通过当作区域证明。

## 3. 多个同输入快照：仿射残差见证

仅对同一输入 `g` 累积快照

$$A_{s_l}(h_l)x_l=g-d_l,\quad X=[x_1,\ldots,x_k],\quad
v=Xw,\quad \mathbf1^Tw=1.$$

系数和约束消除残差中的 `g` 项。残差分成

$$r=\sum_lw_ld_l+
\sum_iH_iX\operatorname{diag}(h_{l,i}-h_i)w+
CX\operatorname{diag}(s_l-s)w.$$

只预计算 `M_i=X^T H_i X`、`M_C=X^TCX`、`X^TK_0X` 和 `X^Tg`，有

$$B_b(w,h)=\sum_i\frac{w^T\operatorname{diag}(h_{l,i}-h_i)
M_i\operatorname{diag}(h_{l,i}-h_i)w}{h_i},$$

$$B_s(w,s)=\frac{w^T\operatorname{diag}(s_l-s)M_C
\operatorname{diag}(s_l-s)w}{\alpha+s},$$

$$B_d(w,s)=\frac{k\sum_l w_l^2\|d_l\|_{C^{-1}}^2}{\alpha+s}.$$

三角不等式给出 `||r||_(A^-1) <= sqrt(B_b)+sqrt(B_s)+sqrt(B_d)`。
选择 `w` 时最小化三个二次型之和，保持 `sum(w)=1`；为处理近依赖快照，
加入非负 ridge，并在证书中保留相应安全项。最后仍用上一节的 `q` 和
残差上界计算 `U`。这不是新 Galerkin 定义，也不改变交付模型。

查询需要小型线性求解 `O(k^3)` 和 `O(pk^2)` 二次型，基更新还需边界
投影。维数 `p` 的代价没有消失；避免的是参数覆盖网格。

### 两个预算有限的判决原型

1. 固定 `s=0`，每轮当前空间冻结，抽取 256 个新参数，计算上述证书；
   找到第一个失败点便进行一次真实求解。最多 24 次，另以新 4096 点诊断。
2. 每输入先处理 `s=0`，再按原椭圆移位计划降序处理；不同移位的同输入
   快照可复用。每轮抽取 64 个新参数，取第一个证书失败点扩充。
   诊断在新的 4096 参数上对四输入和全部有限移位取联合最大值。

这里证书进入了发现失败和富集的循环，没有全域取最大值。256/64 个
通过只是本轮判决的训练停止规则，**不是高置信度风险接受**。新 4096 点
仅诊断其泛化和松弛，不把它包装成完整提取算法的事后验收。
若要成立真正的联合任务风险定理，还需全时间证书、合法的序贯概率
预算和 SVD 处理；本轮因成本门槛失败而不推进。

## 4. 数值证据与判决

**判决边界：** 否定本轮单快照对角覆盖的实用性，以及当前跨移位仿射见证原型

不重启共享空间、全域贪心或参数细分调优。


## 5. 复现与限制

从仓库根目录执行，依赖与现有原型相同：

```bash
for task_seed in 20261010 20261011 20261012; do
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python playground/adaptive_bci_sampling/anchor_coverage_gate.py \
    --seed "$task_seed" --mixed \
    --output "playground/adaptive_bci_sampling/results/anchor_coverage_seed${task_seed}.json"
done
python -m py_compile playground/adaptive_bci_sampling/anchor_coverage_gate.py
```

密集谱参考只允许不超过 2000 自由度；正式大规模证书不能复用这一参考
路径。当前小模型门槛未通过，没有启动 47k/122k 正式测试，避免将无效
构造的规模扩大当作研究进展。

同输入仿射见证是残差对偶范数上界的一个特化，不宣称学术新颖性。
参数域局部化、风险导向自适应和残差认证已有先行工作，例如
[adaptive local reduced basis and risk](https://doi.org/10.1016/j.cma.2018.10.028)
与 [exact-solution certificates and spatio-parameter adaptivity](https://doi.org/10.1137/16M1071341)。
本轮可以保留的独立结果是：便宜的边界残差见证可用于固定实移位的
逐源训练检查；它尚未解决动态尾项、SVD 或提取经济性。
