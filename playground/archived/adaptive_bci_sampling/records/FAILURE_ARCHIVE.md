# 失败路线档案（定性版）

本档案仅保留**具体配方为何没有采用**，以及发现过的证明漏洞、误差度量错配或实现问题。它不记录数值结果，也不声称否定相应的整个数学方法族。以往更详细的实验说明和测量值可以查阅 [原有 Git 版本](https://github.com/catyugu/MetaHotspot/blob/358b2b6b19709fb80b115c64ad2c888e1290a3ab/playground/adaptive_bci_sampling/records/FAILURE_ARCHIVE.md)。

口径说明：`PORT-SYSTEM` 是历史端口动态系统范数，`PORT-STEP` 是有限时刻端口观测，`PORT-FIXED-S` 是固定实移端口缺陷，`STATE` 是全场状态误差，`COST` 是完整计算成本。不同口径的失败不能互相外推；SVD 前结论不能直接作为最终交付基的结论。近期跨对话路线另见 [研究台账](RESEARCH_SYNTHESIS_2026-10-17.md)。

## 端口动态桥与固定实移证书

| 编号与路线 | 淘汰原因或限制 |
| --- | --- |
| 历史端口二次动态桥 | 固定移位的二次匹配缺陷不能推出动态系统范数的同阶界；未否定加入额外结构的其他桥 |
| A1 全局 matrix-fractional Bernstein + Neumann | 全盒界过松；细分和升阶又使认证成本过高 |
| A2 全盒 Taylor jet | 覆盖宽参数盒需要高阶展开，成本难以承受；只否定旧实现 |
| A3 局部 Neumann / Chebyshev + Bernstein | 细分与升阶仍难完成闭合，局部逆多项式代价高 |
| A4 Reduced Neumann–Bernstein | 界可在部分场景闭合，但生成证书比提取基线昂贵 |
| A5 全局单谱标量残差上界 | 严格但丢失方向信息，不能作为实际停止条件 |
| A6 BDF1 输出残差上界 | 时间递推界过松，即使局部更新逆算子仍不能解决 |
| A7 将 raw 快照证书传给 post-SVD ROM | 压缩改变空间并可能显著放大误差，证书不可直接继承 |
| A8 旧频率谱计划 | 部分低 HTC 误差未覆盖，且历史缓存键错误污染了初始测量；只限当时计划 |
| A10 频率轴 Hankel 全盒界 | 算子包围过松，按参数与频率网格构造 Gram 成本失控 |

## 确定性采样、贪心与频移安排

| 编号与路线 | 淘汰原因或限制 |
| --- | --- |
| B1 闭式 Chebyshev / Padua / Smolyak 点集 | 连续保证所需点数大，且未覆盖 closing SVD 的损失 |
| B2 只取参数盒角点 | 漏掉混合参数方向，角点不必张成合适的响应空间 |
| B3 加密 Padua / Smolyak 后直接 SVD | 截断空间不嵌套，更多快照也可能导致更差交付误差 |
| B4 张量 Zolotarev 点数规则 | 过度保守，一维有理逼近界不足以证明张量交叉响应误差 |
| B5 Zolotarev 种子 + weak greedy | 候选网格上的最坏值无法直接认证连续参数盒，离线选点不廉价 |
| B6 种子 + 单个切角 | 无法同时保护暴露边的不同区域 |
| B7 种子 + 多切角 | 添加快照经 SVD 后并不保证改善；同阶输出可能退化 |
| B8 BDF1 残差 greedy | 用来引导选择的界偏松，迭代与审核开销不合理 |
| B9 conditional Zolotarev 暴露边 | 一维放置准则与最终多输入输出误差目标错配 |
| B10 四角凸二次 majorant | 对实际误差曲率和方向不敏感，且只适用于特定未压缩空间 |
| B11 场残差 greedy | 名义 step 通过不能补救最坏 transfer 未达标 |
| B12 扩大 Zolotarev 初始种子 | 增加解数，却未改善关键方向的交付误差 |
| B13 固定张量 Zolotarev 采样 | 固定采样代价过高，未构成可比的端到端改善 |
| B14 加密 greedy 候选网格 | 更细的离散候选集不保证压缩后或 holdout 表现改善 |
| B15 收紧 closing SVD 截断 | 可以补救误差，但最终阶数和成本上升，节省来自更大空间 |
| B16 稳态 greedy 直接用于动态多频移 ROM | 观测通过但其他 transfer 仍超限；raw 证书不适用于最终基 |
| B17 稳态 greedy + 加密网格 | 仍未解决最终交付基的误差和连续箱覆盖 |
| B18 稳态 greedy + 更紧 SVD | 改变了交付阶数与截止条件，不能宣称同条件效率优势 |
| B19 多 HTC 低频面设计 | 有限 step 诊断尚可，但稳态 transfer 未满足自身标准，频段选择缺证明 |
| B20 只在单个种子补 DC | 低频覆盖不完整，稳态误差仍有缺口 |
| B21 多组 HTC 的全局面评分 | 参数组变多后选点退化，原始数据出处也不完整 |
| B22 全频移切角设计 | 多做频移响应而没有比低频面更好的交付质量 |
| B23 局部 DC 增补 | 小规模验证集通过不能外推到更广的参数集合 |
| B24 稀疏直接 LU 扩展到大模型 | 分解准备与内存成本过高；实 SPD 逆作用优先 AMG 迭代法 |

## 压缩、缺陷分解与响应映射

| 编号与路线 | 淘汰原因或限制 |
| --- | --- |
| C1 inexact-moment 动态桥 | 最终空间的秩和对称兼容性不满足定理前提，关键误差不等式失效 |
| C2 交付基的桥量直接估计 | 压缩损失和最终误差难以分离，界量本身不便宜 |
| C3 inexact-RK 的 LU 缓存测量 | 分解仅按 shift 缓存，错误复用了其他参数点的矩阵 |
| C4 逐频移加性 defect 预算 | 简单相加过分保守，掩盖了压缩占主导的机制 |
| C5 active-set 边界截断 | 小模型稀疏结构不代表真实求解便宜，绝对阈值也不控制相对误差 |
| C7 原样 stock 最终基的事后盒审核 | 某些基在固定实移目标上本身不达标；事后拒绝不能成为无需再富集的提取方案 |
| C9 边界 Green 块低秩耦合 | 局部近似可好，但全局界太松，准备参考块也过于昂贵 |

**有用但不足以闭合的诊断**：span 内残差感知压缩和稳定 QR 残差表示可改善数值评价；它们仍不保证连续参数域或动态误差。历史文档中对 vendor 范数和归一化的某些表述已撤回，不能继续作为交付条件。

## 面向最终动态交付量的代理方法

| 编号与路线 | 淘汰原因或限制 |
| --- | --- |
| E1 按冲激 POD 能量排序截断 | 平均能量与最坏输入组合错配，局部激励的重要快模态容易被丢弃 |
| E2 只补 `C^{-1}G` 高频尾部 | 可以消除高频极限缺口，却不能解决主导中频误差 |
| E3 用固定实移 `D_fix` 驱动动态提取 | 单频残差小不推出全时间 impulse 保真 |
| F1 ratio-native Sylvester 桥 | 对非不变空间的放大项太松，富集又很难降低它 |
| F2 锚点标量公式 | 严格但随单元变化过于保守，难作有效验收 |
| F3 锚点公式的严格度量版本 | 刚度与质量范数混用，无法满足关键收缩条件 |
| F4 单元 coercivity 常数 | 在宽 HTC 范围需要大量细单元，证书成本不可行 |
| F5 锚点 transfer 差分替代 coercivity | 估计整个传递算子的变化，丢失 ROM 已捕获方向上的抵消 |
| F6 Lipschitz 导数包络 | 三角放大和小分母造成过松的全方向界 |
| F7 gap 证书的导数形式 | 近奇异权重导致导数界虚高，直接处理函数值更有希望 |
| F8 `B_metric` 的导数算子范数 | 未充分利用主特征方向的稳定性 |
| F9 `beta/alpha` 标量化链 | 分别取范数相加，破坏两个扰动贡献之间的抵消 |
| F10 transfer sandwich / operator convexity | 严格弦界的局部误差较大，需要过多分片 |
| F11 直接求全阶 KYP SDP | 缺少生产可行性证据，问题规模预计不合理；**未实测失败**，只是不作为主线 |

## 单元细分、频率变量与实现缺陷

| 编号与路线 | 淘汰原因或限制 |
| --- | --- |
| G1 依赖均匀采样网络证明盒上连续误差 | 角点扫描的表面收敛不能控制点间余项 |
| G2 均匀 HTC 单元细分 | 对数分区在绝对尺度上不均匀，困难单元导致整体细分成本过高 |
| G3 粗单元上的低阶多线性余量 | 不细分时曲率界太松；不否定细单元上的同一方法 |
| G4 曲率余量使用算子范数或错误特征值符号 | 界过松或符号不对，应控制负的最小特征值方向 |
| G5 直接对频率 `omega` 插值 | 零频附近存在不合适的奇异行为；倒频率变量更自然但尚未闭合 |
| H1 `shares` 变量遮蔽 | 扫描并未按预期覆盖各单元全部采样点，旧结果应作废 |
| H2 缺失频率静默设零 | 二维调用路径没有真正按所需频率求值，应当 fail fast |
| H3 跨不同基底比较 `sup` 或证书 | 未绑定基底身份、容差及阶数的记录不可比较 |
| H4 对虚轴复非 Hermitian 算子使用 CG | 求解器类别错；复移位需另配适当 Krylov 法与预条件 |
| H5 动态极小极大贪心的 Gramian 与停止实现 | 权重矩阵写错，且误以为每次富集的最坏误差单调下降 |

## 随机化富集与连续风险闭环

口径说明：以下路线均保持 MPMM 原定椭圆实移与逐输入独立响应空间，只改动全阶快照选择、最终截断阶数和停止/审核机制。结论来自独立合成模型上的原型实验，只登记机制与适用范围，不记录数值。

| 编号与路线 | 淘汰原因或限制 |
| --- | --- |
| N1 随机化失败质量调度 + 最终风险审核 | 在与基线采用相同最终选阶口径和相同审核要求时，全阶求解次数没有稳定减少，墙钟时间反而更长，最终 ROM 阶数明显增大；替换选点规则本身不构成效率优势 |
| N2 只重定最终 SVD 选阶的消融 | 保留基线原有快照、仅重新决定最终截断阶数并做独立审核，即可通过同一审核且无需新增全阶求解；说明本轮观察到的收益来自压缩阶段，把它归因于新采样配方不成立 |
| N3 实移联合残差风险审核到动态保真 | 通过固定实移联合残差风险审核的基底，其全场冲激响应相对误差仍可超过同一容差；RES-PRE 口径的风险认证不能充当最终动态交付量的保证 |
| N4 原定频移上的有理插值界与最小谱间隙 Duhamel 界 | 前者用于认证整条动态响应过于松弛；后者在弱散热模型上严重高估实际误差；两者都不足以成为动态认证主线 |
| N5 低维 Galerkin 逆的 Taylor–Bernstein 单元包围 | 不需要逐单元 Riesz 求解，数学上可闭合，但非均匀模型上收敛困难，且浮点舍入尚未被包围；作为连续域认证备选成本偏高，未被否决但不作为默认提取器 |

N2 与 N3 的结论相互独立：前者说的是**收益归属**，后者说的是**控制量口径**。两者都要求后续比较同时固定选阶截止条件与审核口径，否则无法区分采样创新与压缩修复的贡献。

| 编号与路线 | 淘汰原因或限制 |
| --- | --- |
| N6 成本归一化的方向覆盖效用 | 用「预计消除的失败残差方向质量 ÷ 预计全阶求解成本」做随机化选点，未获得稳定的端到端收益；只做方向覆盖同样不能稳定胜出。该效用目前只是设计动机，不是已验证的配方 |
| N7 单纯按最大残差选点 | 可以减少全阶求解次数，却倾向于挑到更难求解的参数点，累计 Krylov 迭代反而上升；快照数下降不等于单位计算成本下降 |
| N8 缩短局部连续合格次数并配合最终风险审核 | 能完成同一审核，且平均全阶求解更少，但交付阶数与墙钟存在波动；缩短局部停止规则只能作为风险闭环的一部分，不能单独作为效率结论 |
| N9 多移位 Lanczos 动态误差判别器 | 代数路线可行，但在弱散热模型上需要极深的 Krylov 空间，当前成本无法支撑大规模闭环认证；与既有「Riesz–Lanczos 动态误差包围」的限制一致，归并到该条 |
| N10 探索保护的失败区域重采样 | 用 q=γμ+(1−γ)ν 把失败参数区域反馈进采样分布，相对同等最终风险闭环的**纯随机**富集没有稳定优势（胜、负、平混杂）；对比未经认证的基线所看到的收益不能归因于该重采样机制本身 |
| N11 按局部能量误差下降挑选被截断的 SVD 方向 | 把非前缀 SVD 选阶做成贪心，在随机风险闭环中发生停滞；同一份快照下，改变选阶带来的收益不应计入采样创新 |
| N12 软失败加权 / 方向加权随机选点 | 在配对随机种子的对照中，平均全阶求解数下降，但首次独立审核完全通过的次数反而减少，且额外残差探测更多；软加权不能替代「压缩口径统一 + 独立审核」 |
| N13 单锚点动态耗散（Riesz）证书及其角点收紧 | 单锚点逆算子上界过于保守，多数参数点被误拒；改用参数盒角点矩阵凸性包围可以收紧，但需要数百次额外 AMG 逆作用，认证成本已与整次提取相当。该控制量本身可证，但目前不构成有性价比的提取闭环 |
| N14 低差异序列 / 批量筛选选点 | 批量 Scrambled Sobol 与批量 IID 筛选都没有稳定战胜普通 IID 抽样；随机低差异序列的覆盖性质不能自动转化成更少的全阶求解 |
| N15 两级动态证书（谱下界 + 方向化 Riesz 收紧） | 在小模型上确实把大部分合格样本的 AMG 尾向量逆作用降到零，但完整墙钟只在约半数配对模型中胜出；严格谱下界随网格细化迅速变保守，已实测与实际最小特征值相差数百倍 |
| N16 有限族联合动态 PAC 审核 | 统计上成立，且在一个 6 种子 × 4 模型的小模型矩阵里多数配对胜出，但仍有种子在给定审核轮数内不闭合、逆作用与墙钟各有倒退；规模仅数百自由度，不足以支撑「在完整动态认证成本下稳定胜出」的结论 |

## 开放但未被否决的研究点

- **角点规律**：实验中的角点控制尚缺整个非仿射 resolvent 余项的证明。
- **倒频率尾部**：高频极限可利用，但频率单元和参数单元如何廉价耦合认证仍未闭合。
- **局部 Neumann 收缩**：粗单元不满足的条件可能通过自适应细分获得；仍需成本与终止性论证。
- **方向化曲率界**：可考虑沿关键输入方向控制余项，而非全空间最坏算子范数；目前没有完成充分验证。
- **最终空间动态风险**：仍缺廉价、可信、纳入 SVD 压缩误差的连续分布风险判别。

本文件只说明旧配方的失败**机制及适用范围**；近期探索不在这里重复，定理与误差对象以 [THEORY.md](../THEORY.md) 为准。
