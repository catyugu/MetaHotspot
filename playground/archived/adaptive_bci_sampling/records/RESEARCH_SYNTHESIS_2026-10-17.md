# 近期宏模型提取路线：问题与处理状态

本文件只梳理 MetaHotspot Project 近期研究路线的**核心缺陷、未决问题及处理状态**，不汇总实验量级、时间、误差、RHS、阶数或逐次结果。详细原始数据应留在各实验运行记录或 Git 历史中。下表既参考历史对话，也参考已有仓库材料；**未获得可追溯生产规模复现的路线，不写成稳定有效的结论**。

## 统一边界

- **RES-PRE**：默认 SVD 前，各输入独立空间在原定实频移上的残差；其风险认证不能自动转移到最终 ROM。
- **FIX-STATE**：固定实移的全输入、全场能量误差；不等于全场动态误差。
- **IMP-FIELD**：全场冲激响应的时间积分误差，需明确是在最终交付空间上衡量。
- **PAC**：给定连续参数分布、误差指标、风险阈值与置信预算的概率保证；不等于对整个参数盒逐点成立。

所有路线比较必须统一控制量、参数分布、输入空间、SVD 阶段、停止标准与完整端到端成本。认证应嵌入富集循环，不能把最后一次免费审核当作效率优势。

## 近期路线

| 路线 | 问题或失败原因 | 当前处理 |
| --- | --- | --- |
| **JFRGE：联合频移残差评价与随机化富集** | 对补齐同一 RES-PRE 风险认证的 stock 有条件优势，但对未经风险补齐的生产流程不构成公平胜出；重复 SVD 与桥接成本影响比较；不认证最终 ROM 动态误差 | 保留为有限口径的参考基线，不宣称普适胜出 |
| **联合频移共享响应空间** | 跨输入空间合并未获得稳定节省，且可能损坏最终 SVD 后精度 | 否决此共享空间配方，保留各输入独立空间 |
| **切向 Krylov / 切向富集** | 新方向不保证覆盖最坏输入组合；额外富集与检查成本未形成稳定的端到端收益 | 暂停作为主线 |
| **随机化联合富集** | 单次跨输入、跨频移共享富集会带入无效方向，最终压缩可能放大缺陷；在相同最终选阶与相同审核口径下也没有稳定的墙钟收益 | 不作为默认配方 |
| **贪心或评分驱动的失败任务选择** | 评分代价不低，最坏任务选择可能局部停滞；离散评分不提供连续域认证；成本归一化的方向覆盖效用也未见稳定收益 | 不采用纯确定性贪心；随机探索可保留 |
| **PACS / 随机跨频移任务调度** | 局部减少求解不能保证墙钟收益；通常只针对 RES-PRE 风险，最终动态保真仍未覆盖 | 保留为待复验的调度候选 |
| **SRG-PAC / 随机梯度富集** | 个别模型有正面迹象，但尚缺异质模型重复验证；代理残差通过仍可能遗漏动态场误差 | 保留研究，不升级为完整宏模型保证 |
| **shiftpilot 与失败样本反馈** | 未经反馈时对某些模型失效；依赖事后修复，风险与训练成本可能转移 | 保留反馈思想，不采用单独选移规则 |
| **Riesz–Lanczos 动态误差包围** | 方向性误差包围可能较紧，但大规模、弱 HTC、连续风险审核时逆作用与迭代开销高；点态判决不等于全盒认证；单锚点耗散证书过于保守，角点凸性收紧又需数百次额外逆作用，认证成本可与整次提取相当 | 数学研究方向，尚非廉价生产证书 |
| **单次 V-cycle / 低精度校正** | 便宜的近似响应不能确保高质量富集，较大模型上成本和精度收益不稳定 | 否决单独替代精确富集的通用宣称 |
| **放宽中间空间容差 + 动态选阶** | 组合收益难拆分，最终审核开销未闭合；放宽容差本身可能导致交付误差超限 | 仅作组合候选，需含认证的同标准比较 |
| **目标导向 SVD / 动态 POD** | 优化代理量与所有输入的最坏场误差不一致；动态标签及优化本身过贵，截断还可能丢掉重要方向；把非前缀 SVD 选阶做成按局部能量误差的贪心也会在风险闭环中停滞 | 不接受简单目标导向压缩作为主线 |
| **参数导数成组富集** | 常规 closing SVD 按能量排序，导数方向可能挤占交付空间而不改善最坏误差 | 否决直接堆叠方向的配方 |
| **统一频移响应空间或多移位合并** | 共享响应空间提升有限，压缩后精度易退化；节约某类运算并非降低总成本 | 不作为当前优先方向 |
| **直接固定实移代理控制动态 ROM** | 固定实移小残差不能推出整个时间域的场误差，缺少匹配的传递定理 | 不得充当 IMP-FIELD 认证 |
| **动态风险联合认证** | PAC 抽样逻辑可成立，但若误差判别需大量全阶动态求解，认证成本会吞没提取收益 | 保留概率框架，另寻廉价且针对最终空间的控制量 |
| **最终 SVD 选阶风险闭环** | 单独重定最终截断阶数即可消除基线大部分最终残差问题，且不需要新增全阶求解；收益来自压缩阶段，记账时不能算作采样配方的贡献 | 保留为独立构件，与采样创新分开评估 |
| **实移联合残差控制量的口径边界** | 覆盖全部输入端口的线性组合，且可在缓存的仿射 Gram 上廉价评价；但实测中通过该审核的基底仍可能超出全场冲激响应容差 | 接受为 RES-PRE 口径的控制量，禁止当作动态保真保证 |
| **Taylor–Bernstein 连续参数单元包围** | 只需已有仿射 Gram，不必逐单元求解 Riesz 问题；数学上可闭合，但非均匀模型收敛困难、浮点舍入未严格包围、成本偏高 | 保留为连续域认证备选，不作为默认提取器 |
| **原定频移有理插值界 / 最小谱间隙 Duhamel 界** | 前者用于认证整条动态响应过于松弛；后者在弱散热模型上严重高估实际误差 | 否决作为动态认证主线 |
| **低差异序列 / 批量筛选选点** | Scrambled Sobol 与批量 IID 筛选都没有稳定战胜普通 IID 抽样；低差异序列的覆盖性质不能自动换成更少的全阶求解 | 不作为选点主线 |
| **两级动态证书与严格谱下界** | 谱下界加方向化 Riesz 收紧能显著减少合格样本的逆作用，但墙钟只在部分配对中胜出；严格谱下界随网格细化迅速变保守，已实测与实际最小特征值差数百倍 | 需要更好的谱下界或新的方向化误差包围 |
| **有限族联合动态 PAC 审核** | 统计上成立，小模型矩阵里多数配对胜出，但仍有种子在给定审核轮数内不闭合、逆作用与墙钟存在倒退；规模仅数百自由度 | 继续作为候选审核机制，需大规模复验 |

## 研究上仍可继承的构件

联合频移的约化残差表达、独立输入空间、失败任务的随机探索、Riesz 加权残差、AMG 预条件迭代法，以及**冻结当前基—独立审核—失败反馈—再抽样**的风险闭环，均可以复用。保留构件不意味着整条旧算法已被验证。

后续需要解决的不是进一步压低某个未经证明的代理量，而是建立能够对**最终交付空间和明确的全场指标**给出可信风险判断、同时负担得起的审核机制。若选择较弱的 RES-PRE 目标，也可以研究和发表，但必须如实限定结论，不能把它称为 IMP-FIELD 保证。
