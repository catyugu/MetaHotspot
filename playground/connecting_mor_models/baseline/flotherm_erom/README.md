# FloTHERM EROM baseline

Curated reference data for the weekly connecting-ROM experiments. Generated
experiment output belongs under `results/` and is not versioned.

The raw simple-cube FloTHERM EROM payload already lives at
`playground/simple_erom_case1/simple_case1_EROM/` and is not duplicated here.
`simple_case1_stress_baseline.csv` freezes the stress-case comparison numbers
used by this work. Baseline source state: MetaHotspot commit
`db1c13cb8bb806ef75b6a5512c1d131d85933815`.
