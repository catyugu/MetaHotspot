# MetaHotspot 进展报告（2026-06-30 ~ 2026-07-06）

## 一、功能开发和修订

- 学习COMSOL优化了自适应时间步进的处理，支持以下四种模式：
  - Free：自由自适应，输出边界上用线性插值获得结果。通常最快但精度略低。
  - Intermediate：确保每两个输出边界之间至少有一次计算。
  - Strict：确保每个输出边界上必须进行一次计算。有助于减少插值带来的额外误差。
  - Manual：严格按照指定时间步长，不做任何自适应。适合于用户精细控制。
- 修订了命令行传参形式，要求用位置无关的双横杠形式进行传参，其中配置文件为必需参数，其余的输出文件名、流体的额外配置文件等为可选参数。
- 彻底把非线性求解器、时间步进器做成模型无关的独立模块，以便日后实验。
