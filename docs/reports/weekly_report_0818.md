# weekly\_report\_0818

## FANTASTIC BCI ROM 工作复现

- 纠正错误观念：我先前总是尝试把边界面片当作功率输入端口，去降阶无源区域成为以端口接入的宏模型，遇到诸多困难，且效果不好。后来经过进一步阅读和实验，发现不应该这样做。事实上根据其技术文档描述，应当直接考虑整体有源模型的降阶将热源作为输入端口，这样做能获得较好的效果，集成到软件中也更加便利。即使要做 embeddable，也该把耦合端口区域当作 BCI 单独构造基底。
- 实验下来的感觉和发现：
  - FANATASTIC 利用椭圆积分给出频率采样点的策略是有效的，最大的好处是充分还原的模型本身的瞬态传播模式（类似覆盖了各种尺度的“时间常数”），可以无视瞬态问题的尺度提取出通用的模型。
  - 预处理时间和降阶后的模式数量随功率源的数量几近线性增加，功率轨迹不同的热源越多，则降阶需要的时间相对越长，降阶后阶数越高，效果相对越差。
  - FANTASTIC 用已有基获得迭代初猜的优化是非常有效的，可以数十倍提升提取的效率。
  - 和网格的关系：增加网格粒度，对提取出来的模式数影响不显著。
  - 对于结温，即热源区域附近的温度还原相对准确，但对冷区的温度还原有时会有误差，且较难以通过提高阶数有效补偿。
- 问题和改进：
  - 原论文中，在新的一组随机仿射参数上残差足够小就退出内循环，这是有一定风险的（有可能新的随机参数较靠近之前的训练值，导致误判），要求数次连续符合残差要求才退出内循环，进入下一个 shift 频点。
  - 基于随机原则的仿射参数采样，据作者宣称，相比贪婪采样有一定优势（可以避免贪婪采样导致的局部停滞问题），但是随机毕竟带来一定程度的不可控，或许有更好的策略？
- 后续问题：
  - 预处理性能
  - 仿射参数范围外推（例如训练时设定 h 为 1 到 1e4，如果使用时用到 0.1 或者 1e5，会如何？）
  - BCI ROM 与 BCI ROM 互联，或者与全量 FVM 域互联
