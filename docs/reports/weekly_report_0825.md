# weekly\_report\_0825

## 实验和优化

- 为第三类边界条件分配额外自由度，在保持准确性同时获得边界条件的仿射性。
- 使用 Ruge Stuben AMG 替代朴素 CG，大幅度加快收敛。
- 确认容差的实际意义，同一个相对容差同时控制频移采样点数量和残差上限。
- 按照论文表述，稳态响应的温升相对误差被容差线性控制，而瞬态冲激响应的温升相对误差基本上是被容差的平方根控制，收敛相对慢（这和我们实验中观察到的情况基本上相符）。
- 残差的语义，可能严重影响相同参数选择下的阶数。论文中没有澄清，可能有以下几种：
    - **$L^2$ 范数**：$\eta = \|\mathbf{r}\|_2$；
    - **加权能量范数**：$\eta = \sqrt{\mathbf{r}^T \mathbf{Ar}}$
    - **相对残差**: $\eta =\frac{\|\mathbf{r}\|_2}{\|\mathbf{b}\|_2}$
- 尝试后得到结论，Flotherm 中的语义比较接近 $L^2$ 范数（在以此作为依据的时候，可以得到和 Flotherm 的阶数更接近的结果），但是仍不完全相同，取 $L^2$ 范数语义时，我们在相同容差取值下的阶数和实际精度仍然稍微多于 Flotherm，不过个位数差异，无伤大雅。
- 提取性能对标，两组仿射参数，范围均为 1 到 1e4：
    - 13 万 DOF：Flotherm ~ 60s，Ours ~ 55s
    - 46 万 DOF：Flotherm ~ 300s，Ours ~ 155s
