# MetaHotspot 进展报告

## 一、功能开发

1. **瞬态求解**：完成了时间推进逻辑和观察点的支持，并新增 transient case1、case2 两组算例用于验证。case2 专门用于各向异性热导率场景的瞬态对比。
2. **各向异性热导率支持**：在材料模型中加入了方向性导热系数的处理能力，可按方向分别指定 kx、ky、kz。
3. **MKL PARDISO 求解器**：新增对 Intel MKL PARDISO 直接求解器的封装，与默认的 AmgCg 迭代求解器并列可选；AmgCg 使用 AMGCL，并根据矩阵性质在 CG/GMRES 间选择 Krylov 方法。
4. **函数类型解析**：在 preprocessor 中新增 function_helpers 模块，支持从 XML 中解析函数的类型标注（边界条件类型、源项类型等），便于后续注册其他函数。
5. **非线性求解器参数传递**：模仿 COMSOL 做法改用右边项/相对容差/绝对容差综合决策。

## 二、后处理算法修正

- **节点插值与边界处理重构**：弃用简单的加权平均，全面采用**多维最小二乘法 (LSQ)** 拟合空间多项式，完成 cell 值到 node 值的温度恢复。同时强化了边界条件的物理优先级：第一类边界 (Dirichlet) 具备无条件强约束决定权；第二、三类边界 (Neumann / Cauchy) 则通过计算面中心外推温度，作为额外的“几何观测点”纳入最小二乘求解器，提升边界附近的温度插值精度。
- **引入各向异性等效距离权重**：针对面到节点的映射权重，此前曾反复对比过体积权重与纯几何距离平方权重，但两者在各向异性介质中均表现不佳。最终决定使用**各向异性等效距离权重**。该方案将方向导热系数 (kx, ky, kz) 融入距离评估，完美从数学上还原了“高导热方向热阻更小、对节点温度影响更大”的物理本质，准确且优雅地处理了各向异性材料下的节点温度恢复。

## 三、架构重构

1. **求解器层重构**：将原来的 `solver` 模块拆分为独立的 `linear_solver`，内部按求解器类型（AmgCg、Pardiso）封装，方便按需编译。
2. **模块合并**：将 `logger` 和 `model` 合并入 `common_lib`，减少库数量；`model/types.hpp` 中的类型定义移入 `core/types.hpp`。
3. **expr 模块改造**：重构了 expr 模块的原生函数注册机制，使绑定接口更加简单易用，同时解除了 command 与 expr 之间的循环依赖。
4. **face_key_processor 简化**：引入 `mesh_utils` 查表替代原先的方向枚举分支判断，`face_key_processor` 逻辑精简。

## 未来计划

- 修改观察点温度计算，使其直接利用当前时间步的单元温度而不是节点温度来插值，乃至考虑异步，以减少额外时间开销
- 瞬态求解的进一步功能增强与调试（当前实现仅支持一阶向后欧拉，未能支持自适应和其他算法，相对粗糙）
- 正确支持第一层可变的 Block 厚度
- 非线性问题的验证和调试，引入 Anderson 加速以更好地处理强非线性问题
- 设计额外配置项目（流体区域、非线性/瞬态求解器的可配置参数，线性求解器的可配置参数）的输入方案
