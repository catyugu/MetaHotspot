# MetaHotspot 进展报告（2026-06-09 ~ 2026-06-15）

## 一、功能开发

1. **时间步进重构 PRD 落地（核心）**：新增时间步进抽象层，提供 BDF1、BDF2、自适应 BDF 三种实现，统一通过工厂创建。Scheduler 内的瞬态主循环被改写为"由 scheme 驱动"的协议：每步由 scheme 选步长与阶、调用装配与非线性求解，再由 scheme 评估是否接受。配置以纯数据结构形式注入，覆盖初始步长、上下限、容差、最大阶数、安全因子、输出帧间隔等。这一改造把"主循环逻辑"与"具体算法策略"彻底解耦，是后续瞬态能力扩展的基础。

2. **集成算例与回归测试**：补齐 BDF2 与自适应 BDF 路径的端到端算例（含参考解），以及固定步长、变步长、启动回退（BDF1→BDF2 提升）等多种场景的单元测试。

3. **探针记录与输出帧对齐**：让探针的记录点与"输出帧间隔"严格对齐——通过 scheme 的输出边界判定，scheduler 只在帧边界处记录。同时修了初始化步长与目标采样点对不齐导致的漏采问题。

4. **首层（layer 0）可变 Z 厚度**：preprocessor 几何解析支持 layer 0 的 Z 厚度由各 block 自行声明，取所有 block 厚度表达式的最大值；其他层与未指定厚度的 block 仍按默认铺满整层处理。同步更新了相关测试。

5. **探针录制下沉到 Scheduler**：探针记录从 main 入口迁移到 Scheduler 内部，初始化时一次性完成绑定；每个时间步只对涉及的少量 cell 做局部采样与拟合（不再展开到全网格节点），与全网格插值共用底层算法以保持精度一致。

6. **构建系统的可选依赖与跨编译器兼容**：构建系统按"mkl / muparser / oneTBB / 其他"分文件管理；oneMKL 改为可选依赖，并修通 MinGW/Clang 下 oneTBB 的链接条件；为 MSVC 用户补上 OpenMP 运行库的拷贝；并修了 muparser 配置与 preprocessor 中若干处实现，让 MSVC 的严格警告也能通过。

7. **新增验证算例**：补一个非线性稳态算例与一个瞬态验证算例。

## 二、后处理 / 数值修正

- **Postprocessor 重整为自由函数 + 采样算法模块化**：将原本的类重整为命名空间下的自由函数集合，并去掉冗余的 IO 职责；底层"在结构化网格的任意位置求温度"算法抽到独立模块，作为全网格插值和探针局部采样共用的基础。

- **时间依赖表达式的时间注入**：插值与探针采样显式接收当前时间，注入到表达式求值上下文中，让时间依赖的边界条件/材料表达式（如 `"500 + 100*t"`）在正确的时刻被求值。

- **非线性残差修正**：把残差计算公式中的 T 从过时的"上一步"改回"当前步"；并简化为纯单步 Newton、残差由调用方提供，同时去掉冗余字段，统一通过历史缓冲的最新槽位访问最新解。

- **局部截断误差与自适应步长控制修正**：重写自适应方案的局部截断误差估计（BDF1 退化情形有专门处理），并以当前温度量级做归一化；同步修正步长安全因子的指数与钳制区间，让自适应步长在主循环里真正生效。

- **各向异性介质后处理修复**：与底层采样算法的各向异性距离权重（按导热系数加权）与沿面法向的导热选取协同工作，简单瞬态 case2 跑通。

## 三、架构变更

1. **网格与 IO 数据模型清理**：移除网格几何结构中的冗余字段（节点坐标、副本计数、层级与单元数等），节点坐标改用内联表达式在消费点重建；材质索引改为通过紧凑映射索引、存储类型收紧；同步更新对应文档反映这些字段的去除与索引策略变更。

2. **time_scheme 模块大幅精简**：通过多轮迭代，消除 time_scheme 对 IO 的直接依赖、合并重复定义、按"初始化 / 选步 / 组装 / 评估 / 输出边界"五段式把抽象层与三个具体方案拉齐。

3. **postprocessor 与 probe 的职责归位**：postprocessor 收敛为少量自由函数；probe 录制完全下放到 Scheduler 内部，与时间步进协同。

4. **表达式后端切换**：为避免大量模板导致的编译卡顿，把表达式引擎整体从原 exprtk 切到 muparser，删除原第三方头文件、新增 muparser 构建配置；清理 expr 模块的死代码；同步修复与之联动的函数辅助器中的上下文处理 bug。

5. **模块重排**：把若干横跨多目录的共用小工具、采样算法、face key 处理、probe 记录器按"归属"重新安放；把部分数据类型从内部模型文件抽到独立的 types。
