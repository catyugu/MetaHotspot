## 工作流程

### 第一步：算法学习——架构确立

- [x] 学习Hotspot, ARTSim和3D-ICE的核心算法和功能特征，进行文档化，确定我们采取的核心算法与公式。
- [x] 特别学习3D-ICE对流体解算和流固耦合传热的处理。
- [x] 特别从ARTSim系统学习如何高效处理非共形网格（例如判断是否相邻，计算交界面热阻等）。
- [x] 学习Hotspot配置文件的写法，为第二阶段的转换做准备。
- [x] 设计一套各流程分离的程序框架与文件/接口规约：
    - 前处理和配置/网格生成（应该为单独的可执行脚本）
    - 流体解算，热解算，结果输出
    - 后处理和可视化（应该为单独的可执行脚本）
- [x] 设计一套完整的正确性验证流程
- [ ] 用文档记录

### 第二步：前处理案例准备

- [x] 依据Hotspot中四个案例和提供的示例toml结构，写一个能将Hotspot的各种（单层，多层，流固耦合等等）求解案例转换成我们自定义的toml文件的脚本。
    - **特别注意**：Hotspot中的功率单元区域的坐标是以本层左下角为原点，你需要进行转换来获得它们的全局坐标区域。
    - **特别注意**：Hotspot中使用csv逐单元格地编码其是固体、流体入口、出口还是仿真域中间的流体块等，你需要正确转换成我们的表达方式：用边界实体组编号来体现边界条件。
- [ ] 确认四个案例都能正确转换（成瞬态和稳态）。

### 第三步：核心算法实现

- [x] 写一个简单的脚本比较我们的结果和Hotspot的结果（瞬态和稳态都要）
- [ ] 实现核心的热仿真算法——验证案例一、二、三
- [ ] 要求：关键层（即Hotspot案例中进行单独输出的版图层）和Hotspot的最大绝对误差在2K以内。
- [ ] 添加流体解算功能——验证案例四
