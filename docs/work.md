# 工作清单

## 项目背景，约束和说明

* 参见[project.md](project.md)
* 目前我们的项目处于Demo（MVP）阶段，因此全面使用Python进行编程。
* 但是必须保证程序本身的通用性。
* **在进入下一个步骤之前，你必须保证前一个步骤的全部任务得到完成。**

## 工作流程

### 第一步：算法学习——架构确立

- [ ] 学习Hotspot和3D-ICE的核心算法和功能特征，进行文档化，确定我们采取的核心算法与公式。
- [ ] 学习Hotspot如何处理非共形网格（例如判断是否相邻，计算交界面积等）。
- [ ] 学习Hotspot配置文件的写法，为第二阶段的转换做准备。
- [ ] 设计一套各流程分离的程序框架与文件/接口规约：
    - 前处理和配置/网格生成（应该为单独的可执行脚本）
    - 流体解算，热解算，结果输出
    - 后处理和可视化（应该为单独的可执行脚本）
- [ ] 设计一套完整的正确性验证流程
- [ ] 提交到git

### 第二步：前处理案例准备

- [ ] 依据Hotspot中四个案例和提供的示例toml结构，写一个能将Hotspot的各种（单层，多层，流固耦合等等）求解案例转换成我们自定义的toml文件的脚本。
    - **特别注意**：Hotspot中的功率单元区域的坐标是以本层左下角为原点，你需要进行转换来获得它们的全局坐标区域。
    - **特别注意**：Hotspot中使用csv逐单元格地编码其是固体、流体入口、出口还是仿真域中间的流体块等，你需要正确转换成我们的表达方式。
- [ ] 确认四个案例都能正确转换。
- [ ] 提交到git

### 第三步：核心算法实现

- [ ] 写一个简单的脚本比较我们的结果和Hotspot的结果（瞬态和稳态都要）
- [ ] 实现核心的热仿真算法——验证案例一、二、三
- [ ] 添加流体解算功能——验证案例四
- [ ] 要求：关键层（即Hotspot案例中进行可视化的版图层）和Hotspot的最大绝对误差在2K以内
- [ ] 提交到git

### 第四步：后处理和可视化

- [ ] 写一个简单的可视化脚本用于把结果映射到2D版图温度分布（就和Hotspot中做的一样）。
- [ ] 写另一个可视化脚本用于利用PyVista展示可交互的结果
- [ ] 提交到git
